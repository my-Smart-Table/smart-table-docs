# Calendar View

Calendar view displays data in a calendar format, suitable for time-related data management.

## Features

### Calendar Display

- Switch between month view, week view and day view
- Records displayed by date
- Support drag to adjust date

### Event Management

- Click a date to create a record
- Drag records to adjust dates
- Support time range display

## Use Cases

- Meeting scheduling
- Schedule management
- Event planning
- Deadline tracking
