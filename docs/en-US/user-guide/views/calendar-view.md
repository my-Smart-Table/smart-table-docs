# Calendar View

Calendar view displays time-based records on a familiar calendar layout. It is perfect for schedules, deadlines, and events.

## Calendar Display

- Switch between month, week, and day views.
- Records appear on the date defined by a selected date field.
- Drag a record to a different date to reschedule it.

## Event Management

| Action | How To |
|--------|--------|
| Create record | Click a date cell to add a new record |
| Edit record | Click an event to open its details |
| Reschedule | Drag the event to another date or time range |
| Time range | Use **Date Time** fields to show events with start and end times |

## Common Use Cases

- Meeting and appointment scheduling
- Content publishing calendars
- Sprint deadlines
- Campaign launch timelines

::: tip Date Field Selection
When creating a calendar view, choose the date field that represents the event date. You can create multiple calendar views using different date fields.
:::
