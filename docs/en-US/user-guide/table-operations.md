# Table Operations

SmartTable provides powerful table operations to help you manage and organize data efficiently. This chapter introduces how to create, edit and manage tables.

## Creating Tables

SmartTable provides three ways to create tables:

### From Template

SmartTable has built-in common templates to help you get started quickly:

1. Click the "+" button in the upper left corner
2. Select "Create from template"
3. Choose a suitable template (project management, CRM, task tracking, etc.)
4. Click "Use template"

### From Blank

If you have specific needs, start from a blank table:

1. Click the "+" button in the upper left corner
2. Select "Create blank table"
3. Enter the table name
4. Click "Create"

### Import Data

You can import data from external files:

::: tip Supported File Formats
- CSV files
- Excel files (.xlsx, .xls)
- JSON files
:::

1. Click the "+" button in the upper left corner
2. Select "Import data"
3. Select the file to import
4. Preview data mapping
5. Click "Start import"

## Basic Table Operations

### Adding Records

Add new records to a table:

1. Click the "+" button at the bottom of the table
2. Fill in the field content
3. Click "Save" or press Enter

**Shortcut**: Press `Ctrl + N` (Windows) or `Cmd + N` (Mac) on the last row

### Editing Records

Edit existing records:

1. Click the cell you want to edit
2. Modify the content
3. Click elsewhere or press Enter to save

**Tip**: All changes are automatically saved to history, and you can undo them at any time.

### Deleting Records

Delete unwanted records:

1. Select the row to delete
2. Right-click and select "Delete"
3. Confirm the deletion

**Warning**: Deletion is irreversible, please operate with caution.

### Sorting and Filtering

**Sorting**:

1. Click the column header
2. Select "Sort ascending" or "Sort descending"
3. Table data is automatically rearranged

**Filtering**:

1. Click the filter icon in the column header
2. Select filter conditions
3. Only records meeting the conditions are displayed

## Advanced Operations

### Batch Operations

Perform operations on multiple records at once:

1. Hold Shift and select multiple rows
2. Right-click and select batch operations (copy, delete, move, etc.)

### Undo and Redo

SmartTable records all operation history:

- **Undo**: `Ctrl + Z` (Windows) or `Cmd + Z` (Mac)
- **Redo**: `Ctrl + Y` (Windows) or `Cmd + Shift + Z` (Mac)

## View Switching

SmartTable supports multiple view modes:

- **Grid View**: Display data in traditional table form
- **Kanban View**: Display task flow as cards
- **Gantt Chart**: Show project timeline and dependencies
- **Calendar View**: Display time-related data on a calendar

Click the view switch button in the upper right corner to switch between views.
