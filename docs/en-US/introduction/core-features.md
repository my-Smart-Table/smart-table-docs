# Core Features

SmartTable provides rich core features to meet personal and team data management needs.

## Multiple Views

SmartTable supports multiple data views to help you see data from different angles:

- **Grid View**: Traditional spreadsheet form, suitable for batch editing and data analysis
- **Kanban View**: Display tasks as cards, suitable for project management
- **Gantt Chart**: Show project timeline and task dependencies
- **Calendar View**: Display time-related events and tasks on a calendar

## Rich Field Types

SmartTable supports 20+ field types:

- Text, long text, number, date
- Select, multi-select, member, link
- Formula, attachment, URL, checkbox

Each field type has specific configuration options to meet different business needs.

## Real-time Collaboration

Supports multi-user real-time collaborative editing:

- View collaborators' cursor positions in real time
- Automatically sync data changes
- Support comments and @mentions
- Detailed operation history records

## Workflow Automation

With the visual workflow designer, you can:

- Set trigger conditions
- Configure automated actions
- Send email notifications
- Call webhooks

## Permission Management

Flexible permission control:

- Role-based permission management
- Field-level permission control
- Table sharing settings
- Public link sharing

## Data Import and Export

Supports multiple data formats:

- Import CSV, Excel, JSON
- Export CSV, Excel, JSON
- Data migration tools
