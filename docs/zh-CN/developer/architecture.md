# 架构设计

本文档介绍 SmartTable 的系统架构设计。

## 技术栈

### 前端

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **状态管理**: Pinia
- **UI 组件**: 自定义组件库
- **实时通信**: WebSocket

### 后端

- **框架**: Flask
- **ORM**: SQLAlchemy
- **认证**: JWT
- **任务队列**: Celery（可选）

### 数据库

- **开发环境**: SQLite
- **生产环境**: PostgreSQL（推荐）
- **缓存**: Redis（可选）

### 部署

- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx
- **文件存储**: 本地存储 / 云存储

## 核心模块

### 数据模型

- **表格 (Table)**: 数据容器
- **字段 (Field)**: 数据结构定义
- **记录 (Record)**: 实际数据行
- **视图 (View)**: 数据展示方式

### 权限系统

- 基于角色的访问控制 (RBAC)
- 表格级权限
- 记录级权限
- 字段级权限

### 实时协作

- WebSocket 连接管理
- 操作广播机制
- 冲突自动解决
- 操作历史追踪

### 工作流引擎

- 触发器管理
- 条件判断
- 动作执行
- 执行日志
