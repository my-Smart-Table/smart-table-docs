# 应用模式

应用模式是一套完整的应用构建与发布体系：基于多维表格能力创建独立运行的应用程序——可视化构建器搭建菜单与页面，发布后生成独立访问地址，终端用户通过独立登录页进入使用。

> 应用模式为**专业版**功能。

## 访问路径一览

| 功能 | 路径 | 说明 |
|---|---|---|
| 应用列表 | `/applications` | 主入口，导航侧边栏可见 |
| 应用构建器 | `/applications/:appId/build` | 编辑 / 创建应用 |
| 应用运行时 | `/application/:appId/runtime` | 已发布应用的访问地址 |
| 应用独立登录 | `/application/:appId/login` | 私有应用的独立登录页 |

## 应用列表

**操作路径**：左侧导航 → 应用（支持搜索、状态筛选、分页）。

| 操作 | 说明 |
|---|---|
| 新建应用 | 填写名称（必填 ≤100 字符）、描述、图标、主题色（默认 `#6366F1`）、访问模式；创建后自动进入构建器，当前用户成为 Owner |
| 编辑 | 任何状态均可编辑；编辑已发布应用需重新发布才生效 |
| 发布 | 仅草稿可发布；版本号 +1，生成发布地址；终端用户即可访问 |
| 取消发布 | 状态回退草稿，终端用户无法访问；已有会话可能过期前仍有效 |
| 删除 | 仅系统管理员或 Owner 可执行；级联删除菜单、页面、组件、权限与会话，不可恢复 |
| 从模板创建 | 打开模板市场选择模板实例化应用 |

## 应用构建器

构建器顶部提供返回、应用名称（行内编辑）、保存、发布/取消发布、预览；包含 4 个标签页。修改后需点击"保存"持久化（有未保存修改时名称旁显示"未保存"标识）。

### 菜单结构

左侧 MenuEditor 树形展示菜单，支持添加、编辑、删除、拖拽排序、可见性切换（隐藏的菜单不在终端用户界面显示）。

| 菜单类型 | 说明 |
|---|---|
| group（分组） | 容器节点，包含子菜单，不可导航 |
| page（页面） | 关联一个应用页面，点击渲染该页面 |
| link（外部链接） | 点击打开外部 URL |

删除分组会同时删除其子菜单。

### 页面配置

页面类型 5 种：**table（数据表格）/ document（文档）/ dashboard（仪表盘）/ view（视图嵌入）/ custom（自定义）**。

- 非自定义页面：简化配置（如 table 类型配置关联的 baseId / tableId、工具栏与编辑开关；view 类型配置 baseId / tableId / viewId）
- **custom 自定义页面**：支持可视化拖拽编辑。组件面板提供 9 种组件：图表、数据表格、筛选器、按钮、文本、图片、容器、标签页、表单；选中组件后右侧属性面板可配置基本 / 样式 / 布局 / 数据绑定 / 事件 / 权限六类属性

::: warning
仅 custom 类型页面支持添加组件；其他类型尝试添加会提示"仅自定义页面支持添加组件"。
:::

### 应用设置

| 配置面板 | 内容 |
|---|---|
| 基本信息 | 名称、描述、图标、主题色 |
| 访问模式 | 私有 private / 公开 public / 令牌 token |
| 独立登录页 | 游客访问开关、登录页标题 / 描述、Logo URL、背景图 URL |
| 主题 | 主色调、Logo URL |
| 移动端支持 | 移动端适配开关、底部导航栏开关 |

### 权限配置

包含两个子标签页：

**角色管理**：内置角色 Owner（全部权限）/ Editor（编辑相关 11 项权限）/ Viewer（查看相关 6 项权限），只读不可改；可添加自定义角色（角色标识唯一），从 15 项权限（应用级 / 菜单级 / 页面级 / 组件级 / 数据级）中勾选。支持为用户分配角色（按用户名/邮箱搜索）、移除分配。

::: warning Owner 保护机制
Owner 角色不可修改、不可撤销，系统会静默阻止相关变更。
:::

**菜单权限**：菜单 × 角色矩阵，为每个角色的每个菜单勾选"可见 / 可编辑"。Owner 的菜单权限始终全部开启。菜单权限依赖菜单结构，需先在"菜单结构"中创建。

## 应用运行时

已发布应用通过 `/application/:appId/runtime` 访问，界面由三部分组成：

- **顶部导航栏**：侧边栏切换、应用 Logo 与名称、全屏、用户菜单（个人信息 / 退出登录）
- **侧边栏**（220px，可折叠至 64px）：渲染菜单树；移动端以抽屉形式替代
- **内容区**：按页面类型渲染 TablePage / DocumentPage / DashboardPage / ViewPage / CustomPage

## 认证与登录

| 访问模式 | 谁可以访问 |
|---|---|
| private（私有） | Owner + 管理员 + 显式分配了角色的用户 |
| public（公开） | 所有已登录用户 |
| token（令牌） | 持有分享链接的用户 |

独立登录页支持用户名/邮箱 + 密码登录（可含验证码），启用游客访问时显示"游客访问"按钮。

| 会话类型 | 有效期 |
|---|---|
| 用户会话 | 7 天 |
| 游客会话 | 24 小时 |

访问未发布的应用将被拒绝；私有应用需先登录并具有相应权限。

## 模板市场

点击"从模板创建"打开模板市场，支持按分类筛选（全部 / 项目管理 / 客户管理 / 内容运营 / 人事管理 / 库存管理 / 通用工具）、搜索与排序（最新 / 最热）。

共 **6 大分类 18 套内置模板**，核心模板如：项目全景仪表盘、CRM 客户门户、个人工作台等。模板卡片展示图标、名称、描述、分类、难度徽章（入门 / 进阶 / 高级）、标签与预计耗时。

**使用流程**：浏览 / 搜索模板 → 点击"使用" → 预览详情（所需表格、菜单结构）→ 确认使用 → 自动创建草稿应用 → 进入构建器自定义。

## 模板导入与导出

- **导出**：构建器中点击"导出模板"，系统从页面配置自动推导依赖表格（`requiredTables`），下载 `.json` 文件
- **导入**：应用列表点击"导入模板"，选择 `.json` 文件；校验合法 JSON、根元素为对象且含 `name` 字段；`requiredTables` 按名称智能匹配已有表格。导入的是模板定义，需通过"从模板创建"实例化为应用

## 常见问题

- **提示"需要登录" / "无权访问该应用"**：会话过期重新登录；私有应用需 Owner 分配角色
- **预览与实际不一致**：编辑已发布应用后需重新发布
- **修改未生效**：构建器修改需手动点击"保存"
- **菜单不显示**：检查菜单可见性开关与菜单权限矩阵中对应角色的"可见"权限
- **移动端布局异常**：在应用设置中开启"移动端适配"；侧边栏在移动端显示为抽屉属正常行为
