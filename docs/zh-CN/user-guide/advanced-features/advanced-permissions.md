# 高级权限

高级权限在基础权限体系（Owner / Admin / Editor / Commenter / Viewer）之上，提供更细粒度的权限控制：通过**权限规则组**将字段、数据、仪表盘、文档等多维度权限聚合为可复用单元，再分配给用户或角色。

> 高级权限为**标准版及以上**版本功能。

## 权限体系层次

```
基础权限体系（Base 级别）
  ├── Owner（所有者）—— 完全控制
  ├── Admin（管理员）—— 管理权限
  ├── Editor（编辑者）—— 读写权限
  ├── Commenter（评论者）—— 评论权限
  └── Viewer（查看者）—— 只读权限
        ↓
高级权限体系（规则组级别）—— 覆盖 / 细化基础权限
  ├── 字段列权限 —— 控制单字段的查看 / 编辑
  ├── 数据权限 —— 控制数据可见范围
  ├── 仪表盘权限 —— 控制仪表盘访问
  └── 文档权限 —— 控制文档访问
```

## 权限规则组管理

**操作路径**：进入 Base → 权限管理 → 规则组

| 操作 | 说明 |
|---|---|
| 新建规则组 | 填写名称（必填，≤100 字符）与描述，保存创建 |
| 编辑 | 修改名称与描述 |
| 启用 / 禁用 | 列表中切换开关；禁用后规则组不生效但保留配置 |
| 复制 | 复制全部规则明细与数据条件（不含分配关系） |
| 删除 | 级联删除规则明细、数据条件与分配关系，不可恢复 |

## 字段列权限

精确控制用户对特定字段列的访问，适用于隐藏敏感字段（薪资、身份证号）、控制关键字段编辑等场景。

**配置方式**：规则组编辑 → 字段权限 Tab。界面以树形展示 Base 下所有表格 → 字段，支持批量设置。

| 权限值 | 说明 |
|---|---|
| `none` | 禁止访问，字段不可见 |
| `read` | 只读，可查看不可编辑 |
| `write` / `edit` | 可查看和编辑 |

字段权限优先级最高：为字段设置 `none` 后，即使该用户是 Base 的 Editor 也看不到该字段；设置 `write` 后，Viewer 也能编辑该字段。

## 数据权限

控制用户对记录的可见范围，两种模式：

### 仅自己创建

规则组编辑 → 数据权限 Tab → 选择"仅自己创建的数据"。用户只能看到自己创建的记录；Owner / Admin 不受限。

### 条件筛选

按条件动态筛选可见数据：

- **操作符**：文本（等于 / 不等于 / 包含 / 不包含）、数字与日期（大于 / 小于 / 大于等于 / 小于等于）、布尔与成员（等于 / 不等于）、通用（为空 / 不为空）
- **动态变量**：`{current_user.id}`、`{current_user.name}`、`{current_user.email}`
- **逻辑组合**：多个条件支持 AND / OR 组合，例如：`部门 = "销售部" AND 负责人 = {current_user.id}`

字段权限与数据权限同时存在时：先按字段权限过滤列，再按数据权限过滤行，用户看到的是"可见字段 × 可见记录"的交叉结果。

## 仪表盘与文档权限

| 资源 | 权限值 | 说明 |
|---|---|---|
| 仪表盘 | `none` / `view` / `edit` | 禁止访问 / 可查看 / 可编辑布局和组件 |
| 文档 | `none` / `view` / `edit` | 禁止访问 / 可查看 / 可编辑内容 |

配置方式：规则组编辑 → 仪表盘权限 / 文档权限 Tab，为每个仪表盘或文档设置权限值。

## 自定义角色

每个 Base 创建时自动初始化 5 个**系统预设角色**（Owner / Admin / Editor / Commenter / Viewer）：不可删除、只能修改描述。

**创建自定义角色**：Base → 权限管理 → 角色管理 → 新建角色，填写名称与描述保存。

**为角色分配规则组**：角色详情 → 权限规则组区域 → 选择规则组 → 分配。属于该角色的所有用户自动继承权限。

## 权限分配

支持两种分配方式：

| 方式 | 说明 |
|---|---|
| 用户直接分配 | 权限管理 → 权限分配 → 为用户分配规则组 |
| 角色继承 | 规则组分配给角色，角色成员自动获得 |
| 批量分配 | 权限分配 → 批量分配，一次为多个用户分配同一规则组 |

**有效权限预览**：选择用户 → 权限预览，可查看该用户最终生效的字段权限、数据权限、仪表盘与文档权限汇总。

## 权限优先级机制

```
字段列权限  >  数据权限  >  基础 Base 权限
  (最高)            ↓              (最低)
              仪表盘/文档权限
```

- 字段权限覆盖所有其他层级（Editor 的字段设为 `read` 则只读；Viewer 的字段设为 `write` 则可写）
- 数据权限限制基础权限的可见范围
- 无规则组配置时回退到基础 Base 角色权限
- 多个规则组配置同一资源时，取最高权限值（`write > edit > read > view > none`）

## 常见问题

**权限未生效？** 依次检查：① 规则组是否被禁用；② 用户是否已通过用户直配或角色分配获得规则组；③ 权限缓存（最长 1 小时）是否未刷新——可由管理员清除缓存。

**数据权限条件不生效？** 检查字段 ID 是否正确、条件值与字段类型是否匹配、动态变量拼写、AND/OR 逻辑关系。

**角色无法删除？** 系统预设角色不可删除；仅自定义角色可删除，删除会级联清除其规则组分配与成员引用。

**性能建议**：单个 Base 下规则组不超过 50 个、自定义角色不超过 20 个。权限检查结果缓存 1 小时，权限变更后受影响用户的缓存自动失效。
