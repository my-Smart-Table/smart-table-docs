# 打印

打印功能提供"**可视化模板设计 + 数据填充打印**"能力：拖拽式设计打印模板，打印时自动填充记录数据，显示值与表格视图一致。支持模板共享、导入导出、逐条 / 汇总两种批量打印方式，以及预印单据套打。

> 打印为**标准版及以上**版本功能。打印为纯前端渲染（hiprint 引擎），通过浏览器打印对话框完成，无需安装客户端。

## 入口与权限

进入 Base 工作区的**表格视图**，顶部工具栏可见**「打印」**下拉按钮（导入/导出按钮旁）：

| 菜单项 | 说明 |
|---|---|
| 快速打印 | 选择模板与数据范围，预览后打印 |
| 管理打印模板 | 模板的新建 / 编辑 / 删除 / 共享 / 导入 / 导出 |

权限规则：使用模板打印需 Base 成员（Viewer 及以上）；新建模板需 Editor 及以上；编辑/删除他人模板需 Base Admin/Owner。模板可见性分**私有**（仅创建者）与**共享**（角色不低于设置的"最低使用角色"）两种。

## 模板管理

点击「管理打印模板」打开管理对话框，列表分为**我的模板**与**共享模板**两组。

- **新建 / 编辑设计**：打开全屏设计器，拖拽设计后填写名称保存。系统有防误覆盖保护：画布意外为空而原模板有内容时，保存会二次确认
- **权限设置**：选择私有 / 共享（并设置最低使用角色）
- **导出**：下载 `.json` 文件（跨 Base / 跨实例共享）；设计器顶栏「导出」可导出未保存的当前设计
- **导入**：选择 `.json` 文件，系统校验文件类型（`smart-table-print-template`）、版本与大小（≤1MB）；若模板绑定的字段在当前表不存在，会黄条提示且不阻断导入，导入后以私有可见性创建
- **复制 / 删除**：复制生成私有副本；删除需二次确认

## 模板设计器

设计器为全屏界面：顶部标题区（模板名称 / 可见性 / 描述）+ 工具栏 + 左侧面板 + 设计画布 + 右侧属性面板。

**工具栏**：

- 纸张类型：A3 / A4 / A5 / B3 / B4 / B5 / 自定义（宽高 mm，10–500）；显示页码开关
- 缩放（50%–200%，仅影响设计视图）、旋转（横竖向切换）、清空
- 预览（取表格第一条记录作为示例数据，与正式打印效果完全一致）、导出、保存模板

**左侧面板**（三段可折叠分组）：

| 分组 | 内容 |
|---|---|
| 常用元素 | 文本、多行文本、**数据表格**、图片、条形码 / 二维码、横线 / 竖线 / 矩形 / 椭圆 |
| 系统字段 | 创建时间、更新时间、创建人、更新人，直接拖入即可 |
| 表格字段 | 当前表格全部字段，图标与字段类型一致 |

### 数据表格元素（表格汇总打印的核心）

"表格汇总"模式将所有记录渲染成一张大表格，需要使用**数据表格**元素：

1. 从常用元素区拖入数据表格（默认 3 列占位）
2. **点击列选中 → 双击表头文字** → 从内联下拉中选择字段，列自动绑定（列标题更新为字段显示名）
3. 保存模板，快速打印时选择「表格汇总」模式

::: warning field 填字段 name 而非 ID
列的 `field` 必须与字段的 **name** 完全一致（如 `amount`），填字段 ID（如 `fld_abc123`）会导致列空白。数据表格元素自身属性面板中的 field 保持默认 `table` 不要修改。
:::

**模式选择建议**：

| 场景 | 推荐 |
|---|---|
| 合同、发票、标签（单条一页） | 逐条打印 + 普通字段元素 |
| 报表、清单、对账单（多条一页） | 表格汇总 + 数据表格元素 |
| 字段多于 10 列 | 建议逐条打印 |

## 快速打印

点击「打印 → 快速打印」：

1. **选择模板**：当前表格下可见的全部模板
2. **数据范围**：勾选的 N 条记录（需先在表格勾选行）/ 当前视图全部记录
3. **打印方式**：逐条打印（每条一页）/ 表格汇总（单页列表，模板需含数据表格元素）
4. 预览分片渲染（每 10 条一片，最多预览前 50 条），确认后发送至浏览器打印对话框

**浏览器打印设置建议**：边距选"默认或无"；缩放固定 **100%**（勿选"适合页面"，会破坏毫米定位）。

## 字段显示值规则

打印输出的值与表格视图显示保持一致：单选 / 多选显示选项名称，成员显示用户姓名，关联显示记录标题，附件显示"N 个附件"，公式显示计算结果，日期按表格时区格式化。**签名字段**自动作为图片元素打印（attachment 预取为 base64 DataURL），签名为空时该区域留空。

## 套打（预印单据）

在预印好的单据上只打印可变数据：

1. 将空白单据扫描为图片，设计器中插入图片元素铺满纸张置底，作为对齐底图
2. 拖入字段元素，借助标尺 + 网格 + 缩放精确对齐底图格线
3. **删除底图图片元素后保存**（底图不进入打印输出）
4. 打印机偏移校准：纸张设置中调整 `leftOffset` / `topOffset`；系统打印对话框边距选"无"、缩放 100%

浏览器打印精度通常 ±1mm；发票、多联针式单据等严苛场景可接入 electron-hiprint 桌面打印客户端（组件已内置对接能力）。

## 常见问题

- **打印显示 id 而非名称**：确认元素绑定了字段面板中的正确字段，而非手填的 field
- **不想要页码**：工具栏取消"显示页码"
- **导入模板后部分字段为空**：导入时的黄条提示列出了当前表不存在的绑定字段，在设计器中重新绑定后保存
- **预览与打印效果不一致**：将打印机边距设为"无"、缩放设为 100% 后重试
- **能否静默打印**：浏览器打印必须经系统对话框，需静默打印请接入 electron-hiprint
- **日期差了几个小时**：打印按表格时区格式化，检查工作区时区设置
- **设计器预览只有第一条记录**：设计器预览固定取第一条；检查多条记录请用「快速打印」选择数据范围
