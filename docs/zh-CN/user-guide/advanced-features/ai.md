# AI 功能

SmartTable 内置全套 AI 能力：AI 助手对话问答、表格数据语义检索（RAG）、AI 字段批量生成、工作流 AI 节点、仪表盘智能洞察与文档 AI，并配套完整的管理员配置与用量治理体系。
> 审批流为**专业版**功能。

## 功能总览

| 功能模块 | 说明 | 主要使用者 | 入口 |
|---|---|---|---|
| AI 模型配置 | 接入大模型服务商，配置密钥与用途 | 管理员 | 系统管理 → AI → AI 模型配置 |
| 功能域开关 | 按域启停 AI 能力 | 管理员 | 系统配置 → AI → 功能域开关 |
| AI 用量看板 | 用量统计 / 调用日志 / 配额策略 | 管理员 | 系统管理 → AI → AI 用量看板 |
| AI 助手 | 表格对话式问答、统计、写操作 | 所有 Base 成员 | Base 页面顶部 AI 按钮 |
| 表格数据问答（RAG） | 语义检索大表后回答 | Base 成员 | AI 助手内（含索引管理入口） |
| AI 字段 | 按提示词批量生成单元格内容 | 编辑者及以上 | 字段类型选择「AI」 |
| 工作流 AI 节点 | 自动化流程中调用大模型 | 流程编辑者 | 工作流编辑器 → 添加 AI 节点 |
| 仪表盘智能洞察 | 图表解读 / 异常发现 / 图表推荐 | Base 成员 | 仪表盘图表操作「AI 解读」 |
| 文档 AI | 摘要 / 续写 / 改写 / 翻译 | 文档编辑者 | 文档编辑器工具栏「AI 助手」 |
| AI 任务中心 | 批量任务进度查看 | 任务创建者 | 系统管理 → AI → AI 任务中心 |

## 管理员配置（使用前置）

### 配置 AI 模型

**路径**：系统管理 → AI → AI 模型配置。

1. 点击「添加模型」，可选择**预设**自动填充 Base URL、默认模型与参数（内置预设：DeepSeek / 通义千问 / 智谱 GLM / Kimi / MiniMax / 豆包 Seed / 腾讯混元 / OpenAI / Ollama），通常只需填写 API Key
2. 关键字段：**Base URL**（完整 API 根地址，含 `/v1`）、**API Key**（加密存储）、**模型名称**、**用途**（批量任务 / AI 助手 / 向量化 / 图片理解，同一用途可配多个）、**优先级**（越小越优先，主模型故障自动降级）、温度 / 最大 Token
3. 保存后点击**测试连接**，系统自动探测模型能力（工具调用 / JSON 模式 / 流式用量 / 推理）
4. 将模型设为默认并启用

> AI 助手需要模型支持**工具调用**；RAG 需要**向量化**模型；图片理解需要 **vision** 模型。

### 功能域开关与配额

- **功能域开关**：系统配置 → AI，六个域独立启停（AI 字段 / AI 助手 / 工作流 AI 节点 / RAG / 仪表盘智能洞察 / 文档 AI），后端同步校验
- **配额策略**：AI 用量看板 → 配额策略，设置每日 / 每月调用次数与 Token 上限（0 为不限）；达到预算告警阈值（%）时任务中心展示告警，达到限额后 AI 功能暂停调用

## AI 助手

Base 页面顶部点击 **AI 按钮**打开右侧抽屉面板。

- **界面**：欢迎页四张场景卡片（数据查询 / 统计分析 / 字段结构 / 内容生成）；对话区支持完整 Markdown 回复；快捷指令 pills、附件按钮、历史会话与新会话按钮
- **数据查询**：如「帮我查询状态为逾期的记录」「查截止日期大于 2026-10-01 的记录」，结果以卡片展示；支持中文日期与多种日期写法
- **名称语义**：单选/多选直接说**选项名称**，成员字段直接说**用户姓名**，系统自动与存储 ID 互转
- **写操作**（编辑者及以上）：可让助手创建 / 更新记录；**批量更新**属危险操作，助手先弹出**确认卡**（影响记录数 + 前 20 条变更预览），确认后才执行；Viewer 无写操作能力
- **附件理解**：支持图片（vision 模型解析）与文本文件
- **历史会话**：搜索、切换、重命名、删除；与服务端双轨同步
- **敏感字段保护**：标注为 `ai_excluded` 的字段值不会出现在助手上下文、查询结果与 RAG 索引中

## 表格数据问答（RAG）

大表（≥500 行）语义检索问答的前提：**向量化模型已配置**且**该表已建索引**。

- **索引管理**（AI 助手面板右上角，编辑者及以上）：查看索引状态（未索引 / 索引中 / 就绪 / 失败）、重建（后台分批构建）、清空（二次确认）；敏感字段默认不入索引
- **自动增量更新**：记录增删改自动更新索引（仅已建索引的表）
- **小表降级**：行数小于 500 的表自动降级为直接采样读取，无需建索引

## AI 字段

通过提示词驱动大模型为每条记录生成单元格内容。

**创建**：字段区「+」新建字段 → 类型选择 **AI** → 配置提示词模板（通过 `{字段名}` 引用同表其他字段）、输出类型（文本 / 数字 / 单选 / 多选）；可从内置提示词模板库一键套用。

**单条生成**：右键记录行 → AI 生成，内容流式打字机呈现，可停止；写入已有值时二次确认。前置条件：当前表已创建 AI 字段 + 当前用户有编辑权限。

**批量填充**：勾选 ≥2 条记录 → 右键 → AI 填充（N 行）→ 选择字段、确认预估消耗（每条约 1 次调用）→ 开始；单个任务上限 1000 条，进行中可取消（已完成部分保留）。

**AI 任务中心**（系统管理 → AI）：查看批量任务的状态与进度（WebSocket 实时刷新）、失败项逐条重试、执行中取消、预算告警横幅。仅批量填充产生任务；单条生成的消耗在用量看板调用日志查看。

## 工作流 AI 节点

工作流编辑器添加 **AI 节点**：配置系统提示词 / 提示词（支持引用上游变量）、JSON 模式（输出结构化 JSON）；支持**试运行**（不产生流程实例）；失败场景有明确反馈（无可用模型 503、配额不足 429、生成失败 502）。

## 仪表盘智能洞察与文档 AI

- **仪表盘**：图表上点击「AI 解读」——图表解读（趋势要点）、异常发现、推荐图表（可一键应用）
- **文档 AI**：文档编辑器工具栏「AI 助手」——摘要 / 续写 / 改写 / 翻译；处理范围为选中内容或全文；结果可替换（全文替换可在版本历史恢复）、插入或放弃

## AI 用量看板（管理员）

系统管理 → AI → AI 用量看板：

- **用量统计**：近 7 天 / 30 天 / 90 天 / 一年的调用次数、错误数、Token、平均耗时；按日趋势及用户 / 表格 / 模型 / 功能域多维拆解
- **调用日志**：逐条调用记录，可按功能域与状态筛选，详情含输入输出摘要（敏感信息脱敏）
- **配额策略**：每日 / 每月上限与预算告警

## 权限与安全

| 机制 | 说明 |
|---|---|
| 功能开关 | 系统级按域启停，后端同步校验 |
| 模型级 RBAC | 工具按角色下发：查看者无写工具；写操作后端二次鉴权 |
| 确认流 | 批量更新必须人工确认（确认卡 + 一次性 token，防篡改 / 防重放 / 有时效） |
| 敏感字段 | `ai_excluded` 字段值不出现在提示词 / 工具结果 / RAG 索引 |
| 写入审计 | 助手写操作经记录历史留痕（触发者为当前用户）；所有调用写入调用日志 |
| 输出消毒 | 助手 Markdown 回复经 DOMPurify 消毒后渲染 |

## 常见问题

- **测试连接失败（Connection error / 401）**：检查 Base URL 是否含 `/v1`、API Key 是否有效、网络是否可达
- **AI 助手按钮不显示**：确认功能域开关已开启「AI 助手」且用户有 Base 成员权限
- **查询结果为空**：条件值使用选项名称 / 姓名原文（不要填 ID），日期支持多种写法，逐步缩小条件排查
- **提示配额不足**：管理员调整配额策略或等待次日 / 月初重置
- **RAG 找不到相关内容**：确认索引状态为"就绪"，新记录等待增量索引，检查字段是否被排除
- **右键菜单没有 AI 生成 / 填充**：依次检查表内是否已创建 AI 字段、是否有编辑权限、勾选行数（0/1 行显示"AI 生成"，≥2 行显示"AI 填充"）
- **批量任务失败**：任务中心查看失败计数；常见原因：批量任务模型未配置或不可用、配额耗尽、提示词引用了已删除字段
