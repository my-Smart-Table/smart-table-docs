# 协作功能

SmartTable 提供完善的协作功能，支持团队成员高效协同工作。

## 实时协作编辑

多人可以同时编辑同一个数据表：

- 实时查看其他成员的光标位置
- 即时同步数据变更
- 自动解决简单的编辑冲突
- 支持离线编辑和同步

## 评论和@提及

在记录中添加评论：

1. 点击记录打开详情面板
2. 在评论区输入评论内容
3. 使用 `@用户名` 提及团队成员
4. 被提及的成员会收到通知

## 权限管理

### 数据表权限

设置数据表的访问权限：

- **所有者**：拥有所有权限，可以删除数据表
- **编辑者**：可以添加、修改和删除记录
- **查看者**：只能查看数据，不能编辑

### 字段权限

控制字段的访问级别：

- **可编辑**：协作者可以修改
- **只读**：协作者只能查看
- **隐藏**：对特定协作者隐藏

## 共享数据表

### 邀请协作者

邀请团队成员协作：

1. 点击数据表右上角的"共享"按钮
2. 输入协作者的邮箱或用户名
3. 选择权限级别
4. 点击"发送邀请"

### 创建公开链接

通过公开链接分享数据表：

1. 点击"共享"按钮
2. 开启"公开链接"
3. 设置查看权限
4. 复制链接分享给外部用户

## 通知设置

自定义通知偏好：

- 记录被修改时通知
- 被@提及时通知
- 截止日期临近时通知
- 工作流执行结果通知
