# 协作功能

SmartTable 提供强大的实时协作功能，支持多人同时编辑。

## 实时协作

### 多人编辑

- 多人同时编辑同一表格
- 实时同步数据变更
- 自动处理冲突

### 光标同步

- 显示其他用户的光标位置
- 显示正在编辑的字段
- 用户头像标识

### 操作历史

- 记录所有操作历史
- 支持撤销/重做
- 查看修改记录

## 评论与讨论

### 字段评论

- 在字段上添加评论
- 支持 @提及其他成员
- 评论通知提醒

### 讨论区

- 记录级别的讨论区
- 支持富文本编辑
- 支持附件上传

## 权限管理

### 表格权限

- 可编辑：完整编辑权限
- 可评论：只能添加评论
- 只读：仅可查看

### 成员管理

- 邀请团队成员
- 设置成员角色
- 管理权限分配

## 通知设置

### 通知类型

- @提及通知
- 评论回复通知
- 记录变更通知
- 任务分配通知

### 通知方式

- 应用内通知
- 邮件通知
- 浏览器推送
