# 字段类型

SmartTable 提供 **26 种字段类型**，覆盖文本、数值、日期、选择、关联、计算、系统等常见数据场景。选择合适的字段类型，可以让数据录入更规范、展示更直观、计算更高效。

## 字段类型一览

| 类别 | 字段类型 | 说明 |
| --- | --- | --- |
| **文本类型** | 单行文本 | 短文本输入，支持验证规则。 |
| **文本类型** | 多行文本 | 长文本输入，支持多行编辑。 |
| **文本类型** | 富文本 | HTML 富文本编辑器，支持格式化内容。 |
| **数值类型** | 数字 | 整数/小数，支持数字/货币/百分比格式化。 |
| **日期类型** | 日期 | 日期选择器，支持多种日期格式。 |
| **日期类型** | 日期时间 | 日期时间选择器，精确到秒。 |
| **选择类型** | 单选 | 下拉单选，支持自定义选项和颜色。 |
| **选择类型** | 多选 | 标签式多选，支持自定义选项。 |
| **选择类型** | 复选框 | 布尔值开关。 |
| **人员类型** | 成员 | 用户选择，支持当前用户作为默认值。 |
| **联系方式** | 电话 | 电话号码输入和格式化显示。 |
| **联系方式** | 邮箱 | 邮箱地址输入和格式验证。 |
| **联系方式** | 链接（URL） | URL 链接，支持点击跳转。 |
| **媒体类型** | 附件 | 文件上传下载，支持图片预览和缩略图。 |
| **计算类型** | 公式 | 47 个内置函数，支持字段引用和嵌套计算。 |
| **关联类型** | 关联（Link） | 表间关联，支持一对一/一对多/多对多关系。 |
| **查找类型** | 查找（Lookup） | 跨表查询，支持聚合计算（求和/平均值/计数等）。 |
| **系统类型** | 创建人 | 自动记录记录创建者。 |
| **系统类型** | 创建时间 | 自动记录创建时间戳。 |
| **系统类型** | 更新人 | 自动记录最后修改者。 |
| **系统类型** | 更新时间 | 自动记录最后修改时间。 |
| **系统类型** | 自动编号 | 自增编号，支持前缀/后缀/日期格式/补零。 |
| **其他** | 评分 | 星级评分组件。 |
| **其他** | 进度 | 进度条/百分比显示。 |

::: tip 如何选择字段类型
- 需要输入简短内容时选择「单行文本」，长描述选择「多行文本」。
- 需要计算时选择「公式」，需要跨表取值时选择「查找」。
- 需要建立表间关系时选择「关联」。
- 创建人、创建时间等系统字段会自动生成，无需手动维护。
:::

## 文本类型

### 单行文本

用于存储较短的文本内容，如名称、标题、编号等。

**配置选项**：
- 最大长度限制
- 必填选项
- 正则表达式验证

### 多行文本

用于存储较长的文本内容，如描述、备注、会议纪要等。

**特点**：
- 支持多行输入
- 支持换行显示

### 富文本

基于 HTML 的富文本编辑器，适合需要格式化展示的内容。

**特点**：
- 支持加粗、斜体、列表、链接等格式
- 适合编辑说明文档、公告等

## 数值类型

### 数字

用于存储整数或小数，支持灵活的格式化：

- 普通数字
- 货币格式
- 百分比格式

**配置选项**：
- 小数位数
- 最小值/最大值
- 数值格式

## 日期类型

### 日期

日期选择器，支持多种日期格式：

- `YYYY-MM-DD`
- `YYYY/MM/DD`
- `MM/DD/YYYY`

### 日期时间

精确到秒的日期时间选择器，适合需要记录具体时刻的场景。

## 选择类型

### 单选

从预设选项中选择一个值，适合状态、类别等场景。

**配置选项**：
- 自定义选项列表
- 为选项设置颜色标签
- 设置默认选项

### 多选

标签式多选，适合同时选择多个标签或分类。

### 复选框

简单的布尔值开关，常用于标记完成状态。

## 人员与联系方式

### 成员

关联系统用户或团队成员，支持单选或多选。

**特点**：
- 显示用户头像
- 支持将当前登录用户设为默认值
- 常用于任务负责人、项目成员等场景

### 电话 / 邮箱 / 链接

- **电话**：电话号码输入，支持格式化显示。
- **邮箱**：邮箱地址输入，自动校验格式。
- **链接（URL）**：存储外部链接，支持点击跳转。

## 媒体与附件

### 附件

用于上传和管理文件：

- 支持图片、文档、压缩包等多种格式
- 支持图片预览和缩略图
- 文件大小受系统配置限制

## 计算与关联

### 公式

通过公式自动计算字段值，支持 47 个内置函数。

**示例**：

```javascript
// 计算总价
{单价} * {数量}

// 折扣计算
{原价} * (1 - {折扣})

// 条件判断
IF({成绩} >= 90, "优秀", IF({成绩} >= 60, "及格", "不及格"))

// 文本拼接
CONCAT({姓}, {名})

// 日期差
DATEDIF({开始日期}, {结束日期}, "D")
```

更多函数说明请参考 README 中的「公式引擎」章节或后端 API 文档。

### 关联（Link）

建立数据表之间的关联关系，支持：

- 一对一
- 一对多
- 多对多

**典型场景**：
- 订单关联客户
- 任务关联项目
- 评论关联文章

### 查找（Lookup）

从关联表中跨表查询数据，支持聚合计算：

- 求和
- 平均值
- 计数
- 最大值/最小值

## 系统字段

系统字段由系统自动维护，通常不可手动编辑：

| 字段 | 说明 |
| --- | --- |
| 创建人 | 自动记录记录的创建者。 |
| 创建时间 | 自动记录记录的创建时间。 |
| 更新人 | 自动记录最后修改者。 |
| 更新时间 | 自动记录最后修改时间。 |
| 自动编号 | 自增编号，支持配置前缀、后缀、日期格式和补零规则。 |

## 其他字段

### 评分

星级评分组件，适合满意度、优先级等评分场景。

### 进度

进度条或百分比显示，常用于任务完成度、项目进度等场景。

## 字段公共配置

所有字段都支持以下通用配置：

- **字段名称**：显示名称。
- **字段描述**：补充说明。
- **必填选项**：是否必须填写。
- **默认值**：新建记录时的默认值。
- **显示/隐藏**：在视图中的显示控制。
