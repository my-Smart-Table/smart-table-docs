# 字段类型

SmartTable 支持 20+ 种字段类型，满足不同场景的数据管理需求。

## 基础类型

### 文本

- **单行文本**：适合短文本输入
- **多行文本**：适合长文本输入
- **富文本**：支持格式化文本

### 数字

- **数字**：整数或小数
- **进度条**：百分比显示
- **评分**：星级评分
- **货币**：带货币符号的数字

### 日期与时间

- **日期**：年月日
- **时间**：时分秒
- **日期时间**：完整的日期时间
- **创建时间**：自动记录创建时间
- **修改时间**：自动记录修改时间

## 选择类型

### 单选/多选

- **单选**：从预设选项中选择一个
- **多选**：从预设选项中选择多个
- 支持颜色标记

### 下拉选择

- 从下拉列表中选择
- 支持搜索功能

## 高级类型

### 关联字段

- **关联**：关联其他表格的记录
- **查找**：从关联记录中查找数据
- **汇总**：对关联记录进行统计

### 公式

- 支持常用公式函数
- 实时计算结果
- 支持跨字段引用

## 特殊类型

### 成员

- 选择团队成员
- 支持多选

### 附件

- 上传文件
- 支持图片预览
- 支持多种格式

### 链接

- URL 链接
- 自动识别格式

### 邮箱

- 邮箱格式验证
- 点击发送邮件

### 电话

- 电话号码格式
- 点击拨打电话
