# 字段类型

SmartTable 提供丰富的字段类型，满足不同数据存储和展示需求。每种字段类型都有其特定的用途和配置选项。

## 基础字段类型

### 文本字段

用于存储简短的文本内容，如名称、标题等。

**特点**：
- 最大长度：255 字符
- 支持文本格式化
- 可设置默认值

**配置选项**：
- 最大长度限制
- 必填选项
- 正则表达式验证

### 多行文本字段

用于存储较长的文本内容，如描述、备注等。

**特点**：
- 无长度限制
- 支持换行
- 支持 Markdown 格式

**适用场景**：
- 产品描述
- 任务备注
- 会议记录

### 数字字段

用于存储数值数据，如价格、数量等。

**特点**：
- 支持整数和小数
- 可设置数值范围
- 支持数值格式化

**配置选项**：
- 小数位数
- 最小值/最大值
- 数值格式（货币、百分比等）

### 日期字段

用于存储日期和时间信息。

**特点**：
- 支持日期选择器
- 支持时间选择
- 支持日期范围

**格式选项**：
- YYYY-MM-DD
- YYYY/MM/DD
- MM/DD/YYYY

## 高级字段类型

### 选择字段

从预设选项中选择一个或多个值。

**类型**：
- **单选**：只能选择一个选项
- **多选**：可以选择多个选项

**配置**：
- 定义选项列表
- 设置默认选项
- 设置选项颜色

### 人员字段

关联系统用户或团队成员。

**特点**：
- 支持单选和多选
- 显示用户头像
- 支持通知功能

**适用场景**：
- 任务负责人
- 项目成员
- 审批人

### 关联字段

关联其他数据表的记录。

**特点**：
- 建立表间关系
- 支持双向关联
- 支持汇总统计

**示例**：
- 订单关联客户
- 任务关联项目
- 评论关联文章

### 公式字段

通过公式自动计算字段值。

**支持的运算**：
- 数学运算：+, -, *, /
- 文本操作：连接、截取
- 日期计算：日期差、日期加减
- 逻辑运算：IF, AND, OR

**示例公式**：
```
// 计算总价
{单价} * {数量}

// 计算完成百分比
{已完成任务} / {总任务数} * 100

// 生成唯一编号
"TASK-" + YEAR(TODAY()) + "-" + ROW()
```

## 特殊字段类型

### 附件字段

上传和管理文件附件。

**特点**：
- 支持多种文件格式
- 文件大小限制：10MB
- 支持图片预览

**支持格式**：
- 图片：jpg, png, gif
- 文档：pdf, doc, xls
- 压缩包：zip, rar

### 链接字段

存储外部链接地址。

**特点**：
- 自动识别链接格式
- 支持链接标题
- 在新窗口打开

### 复选框字段

用于表示是/否状态。

**特点**：
- 两种状态：选中/未选中
- 可设置默认状态
- 支持筛选和统计

## 字段配置

### 公共配置

所有字段都支持以下配置：

- **字段名称**：字段的显示名称
- **字段描述**：字段的说明文字
- **必填选项**：是否必须填写
- **默认值**：新建记录时的默认值

### 字段权限

可以设置字段的访问权限：

- **可编辑**：所有用户都可以编辑
- **只读**：所有用户只能查看
- **隐藏**：对特定用户组隐藏
