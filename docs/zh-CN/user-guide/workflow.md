# 工作流自动化

SmartTable 的工作流自动化引擎（v1.6.0 新增）可以帮助您将重复性业务流程自动化，例如记录创建后自动发送通知、定期生成报告、满足条件后自动更新字段等。

## 工作流组成

一个工作流由**触发器**和多个**节点**组成：

- **触发器**：决定工作流何时启动。
- **节点**：触发器启动后按顺序执行的步骤。
- **版本管理**：每次保存都会生成版本快照，支持历史回溯。

## 创建新工作流

1. 点击左侧菜单的「工作流」。
2. 点击「新建工作流」按钮。
3. 选择关联的 Base 或数据表。
4. 输入工作流名称和描述。
5. 点击「创建」。

## 触发器类型

| 触发器类型 | 说明 |
| --- | --- |
| **指定时间触发** | 支持一次性触发和重复触发（每日/每周/每月/每年/自定义），可配置截止日期。 |
| **记录创建触发** | 新记录创建时自动触发，支持 AND/OR 多条件组合过滤。 |
| **记录更新触发** | 记录更新时自动触发，可监听指定字段，支持过滤条件。 |

## 节点类型

| 节点类型 | 说明 |
| --- | --- |
| **创建记录节点** | 在目标数据表自动创建记录，支持字段值映射（静态值或引用表达式）。 |
| **更新记录节点** | 自动更新源记录或目标记录的字段值，支持静态值和表达式。 |
| **Webhook 节点** | 调用外部 HTTP 接口，支持选择已有 Webhook 配置或内联配置。 |
| **条件节点** | 根据条件走不同分支，支持 AND/OR 条件组合。 |

### 节点排序

在工作流设计器中，您可以拖拽节点调整执行顺序，灵活控制业务流程。

## 配置示例

### 示例一：记录创建后发送通知

1. 选择「记录创建触发」。
2. 添加「Webhook 节点」，配置通知服务的 URL。
3. 在请求体中使用变量引用新记录字段。

### 示例二：截止日期提醒

1. 选择「指定时间触发」，设置为每日运行。
2. 添加「条件节点」，判断记录截止日期是否等于今天。
3. 条件满足时，通过「更新记录节点」标记提醒状态，或调用「Webhook 节点」发送提醒。

## 版本管理

SmartTable 为每个工作流保存版本快照：

- 查看历史版本列表。
- 对比不同版本的配置差异。
- 回溯到任意历史版本。

## 管理功能

在工作流列表中，您可以：

- 创建、编辑、删除工作流。
- 暂停或继续工作流运行。
- 查看工作流与数据表的绑定关系。

## 执行日志

工作流运行后，系统会记录执行日志：

- 触发时间和触发记录。
- 每个节点的执行状态（成功/失败）。
- 错误信息和重试选项。

::: tip 调试建议
在正式启用工作流前，建议先用测试记录触发一次，检查每个节点的输入输出是否符合预期。
:::

## Webhook 投递管理

工作流中使用的 Webhook 配置支持集中管理：

- 配置名称、URL、HTTP 方法、请求头和请求体模板。
- 设置最大重试次数和重试间隔。
- 测试 Webhook 配置是否有效。
- 查看每次投递的请求参数、响应状态码和响应体。
