# 工作流自动化

SmartTable 的工作流自动化功能可以帮助您自动化重复性业务流程，提高工作效率。

## 概述

工作流由触发器和动作组成：

- **触发器**：当某个条件满足时启动工作流
- **动作**：触发器激活后执行的操作

## 创建新工作流

1. 点击左侧菜单的"工作流"
2. 点击"新建工作流"按钮
3. 选择关联的数据表
4. 输入工作流名称和描述
5. 点击"创建"

## 触发器类型

### 记录变更触发

当数据表中的记录发生变化时触发：

- **创建记录时**：新记录被创建时触发
- **更新记录时**：记录被修改时触发
- **删除记录时**：记录被删除时触发

### 时间触发

基于时间条件触发：

- **指定时间**：在特定时间点触发
- **记录时间到达**：当记录中的日期时间字段到达时触发

### Webhook 触发

通过外部 HTTP 请求触发：

1. 创建 Webhook 触发器节点
2. 获取 Webhook URL
3. 在外部系统中配置请求

## 动作类型

### 发送邮件

向指定收件人发送邮件：

1. 添加"发送邮件"动作
2. 配置收件人、主题和正文
3. 支持使用变量渲染邮件内容

### 创建记录

在指定数据表中创建新记录：

1. 选择目标数据表
2. 配置字段值
3. 支持使用上下文变量

### 更新记录

更新满足条件的记录：

1. 选择目标数据表
2. 设置筛选条件
3. 配置要更新的字段

### 调用 Webhook

向外部服务发送 HTTP 请求：

1. 配置请求 URL
2. 选择请求方法（GET、POST、PUT、DELETE）
3. 配置请求头和请求体

## 条件分支

根据条件执行不同的动作：

1. 添加"条件分支"节点
2. 设置判断条件
3. 为每个分支配置后续动作

## 执行日志

查看工作流的执行历史：

- 执行时间
- 触发记录
- 每个节点的执行状态
- 错误信息和重试选项

## 最佳实践

### 工作流设计

- 保持工作流简单清晰
- 使用有意义的节点名称
- 为复杂逻辑添加注释

### 错误处理

- 为 Webhook 调用添加重试机制
- 配置错误通知
- 定期检查执行日志
