# 场景实践：人事招聘管理

## 适用场景说明

本方案适用于企业人力资源部门对招聘流程进行规范化管理的场景。通过 SmartTable，HR 可以将职位需求、候选人信息、面试安排、录用进度等数据统一管理，并通过视图和自动化提升招聘协作效率。

典型适用对象包括：

- HR 招聘专员管理候选人简历和面试流程。
- 用人部门负责人查看候选人情况和面试反馈。
- HR 主管统计招聘漏斗和渠道效果。

## 推荐的表结构设计

建议创建两张核心数据表：「职位管理」和「候选人管理」。

### 职位管理表

| 字段名称 | 字段类型 | 说明 |
| --- | --- | --- |
| 职位名称 | 单行文本 | 招聘岗位名称。 |
| 所属部门 | 单选 | 如技术部、产品部、市场部等。 |
| 招聘负责人 | 成员 | 负责该职位的 HR。 |
| 招聘人数 | 数字 | 计划招聘人数。 |
| 职位状态 | 单选 | 可选值：招聘中、已暂停、已关闭。 |
| 优先级 | 单选 | 可选值：紧急、高、中、低。 |
| 期望到岗时间 | 日期 | 计划入职日期。 |
| 职位描述 | 多行文本 | 岗位职责和任职要求。 |

### 候选人管理表

| 字段名称 | 字段类型 | 说明 |
| --- | --- | --- |
| 姓名 | 单行文本 | 候选人姓名。 |
| 联系电话 | 单行文本 | 候选人电话。 |
| 邮箱 | 邮箱 | 候选人邮箱。 |
| 应聘职位 | 关联字段 | 关联到「职位管理」表。 |
| 招聘渠道 | 单选 | 可选值：猎头、内推、招聘网站、官网、社交媒体、其他。 |
| 当前状态 | 单选 | 可选值：简历筛选、待约面、面试中、待反馈、offer 发放、已入职、已淘汰。 |
| 面试官 | 成员 | 安排面试的用人部门负责人。 |
| 面试时间 | 日期时间 | 计划面试时间。 |
| 面试反馈 | 多行文本 | 面试官填写的评价和建议。 |
| 期望薪资 | 单行文本 | 候选人期望薪资范围。 |
| 简历附件 | 附件 | 上传候选人简历。 |
| 备注 | 多行文本 | 其他补充信息。 |

## 推荐的视图配置

### 职位管理表视图

- **看板视图**：按「职位状态」分组，查看各职位的招聘进展。
- **表格视图**：展示所有职位信息，便于 HR 主管统一查看。

### 候选人管理表视图

- **看板视图**：按「当前状态」分组，直观展示候选人流转情况。
- **日历视图**：日期字段选择「面试时间」，方便安排面试日程。
- **分组视图**：按「应聘职位」分组，查看每个职位的候选人池。
- **表格视图（按面试官筛选）**：便于用人部门查看自己负责的面试安排。

### 仪表盘建议

- 展示「在招职位数」「各状态候选人数量」「招聘渠道占比」「offer 转化率」等指标。

## 可选的工作流自动化建议

| 自动化场景 | 触发器 | 节点配置 |
| --- | --- | --- |
| 面试提醒 | 指定时间触发（每日运行） | 查找记录节点筛选「面试时间为明天」的候选人，调用 Webhook 节点通知面试官和 HR。 |
| 状态变更通知 | 记录更新触发（当前状态变化） | 当候选人状态变更为「offer 发放」或「已入职」时，通知招聘负责人和用人部门。 |
| 简历初筛分配 | 记录创建触发 | 根据「应聘职位」通过条件节点分配给对应的招聘负责人。 |
| 逾期反馈提醒 | 指定时间触发（每日运行） | 条件节点判断「当前状态为待反馈且面试时间超过 2 天」，提醒面试官尽快填写反馈。 |

## 简要的操作步骤

1. 创建「职位管理」表和「候选人管理」表，配置上述字段。
2. 在「候选人管理」表中添加「应聘职位」字段，关联到「职位管理」表。
3. 创建看板视图、日历视图和按职位分组视图。
4. 录入在招职位信息，并导入或手动录入候选人简历。
5. 安排面试时更新候选人状态和面试时间，面试后填写面试反馈。
6. 配置工作流自动化，实现面试提醒、状态通知和逾期反馈提醒。
7. 搭建招聘仪表盘，持续优化招聘漏斗和渠道效果。
