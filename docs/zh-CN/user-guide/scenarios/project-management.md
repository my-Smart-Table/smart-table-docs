# 场景实践：项目管理

## 适用场景说明

本方案适用于研发团队、市场部门、运营团队等需要对项目任务进行全生命周期管理的场景。通过 SmartTable 的多维表格能力，您可以将任务、负责人、截止日期、优先级、进度等信息集中管理，并通过看板、甘特图、日历等多种视图实时掌握项目进展。

典型适用对象包括：

- 软件研发项目的需求、开发、测试、上线跟踪。
- 市场活动的策划、执行、复盘管理。
- 产品迭代版本的里程碑和任务拆解。

## 推荐的表结构设计

建议创建一张名为「项目任务」的数据表，核心字段如下：

| 字段名称 | 字段类型 | 说明 |
| --- | --- | --- |
| 任务名称 | 单行文本 | 任务或需求的简短标题，作为记录主标题。 |
| 任务类型 | 单选 | 可选值：需求、缺陷、优化、其他。 |
| 优先级 | 单选 | 可选值：紧急、高、中、低。 |
| 负责人 | 成员 | 分配给具体执行人，支持多选。 |
| 状态 | 单选 | 可选值：待处理、进行中、待验收、已完成、已取消。 |
| 所属项目 | 单选 | 用于区分不同项目，如「官网改版」「APP v2.0」。 |
| 父任务 | 关联字段 | 关联到本表，建立任务层级关系。 |
| 计划开始时间 | 日期 | 任务预计开始日期。 |
| 截止日期 | 日期 | 任务预计完成日期。 |
| 完成进度 | 数字 | 使用百分比（0-100）表示当前进度。 |
| 任务描述 | 多行文本 | 补充需求细节、验收标准或备注。 |
| 附件 | 附件 | 上传需求文档、设计稿、测试报告等。 |

如果项目之间存在复杂的依赖关系，也可以额外创建「项目信息」表，通过关联字段将任务与项目关联起来，实现跨表统计。

## 推荐的视图配置

为了从多个维度管理项目，建议配置以下视图：

### 看板视图（按状态分组）

- 分组字段：状态
- 排序规则：优先级降序、截止日期升序
- 用途：直观查看任务在「待处理 → 进行中 → 待验收 → 已完成」各阶段的分布。

### 甘特图视图

- 开始时间字段：计划开始时间
- 结束时间字段：截止日期
- 用途：展示项目时间线，识别关键路径和排期冲突。

### 表格视图

- 显示所有字段，便于批量编辑和快速筛选。
- 可按照负责人或所属项目创建筛选视图。

### 日历视图

- 日期字段：截止日期
- 用途：以日历形式查看每日到期任务，避免遗漏关键节点。

## 可选的工作流自动化建议

| 自动化场景 | 触发器 | 节点配置 |
| --- | --- | --- |
| 截止前提醒 | 指定时间触发（每日运行） | 查找记录节点筛选「截止日期为明天且状态未完成的记录」，调用 Webhook 节点发送提醒通知。 |
| 任务完成通知 | 记录更新触发（状态变更为已完成） | 更新记录节点记录实际完成时间，调用 Webhook 节点通知项目负责人。 |
| 逾期自动标记 | 指定时间触发（每日运行） | 条件节点判断截止日期小于今天且状态未完成，更新记录节点将优先级调整为「紧急」。 |

## 简要的操作步骤

1. 在 Base 中新建数据表，命名为「项目任务」。
2. 按照上文章节添加字段，并为「状态」「优先级」「任务类型」等字段配置单选选项。
3. 创建看板视图、甘特图视图、日历视图，并根据需要设置默认视图。
4. 录入首批任务数据，并通过拖拽调整看板中的任务状态。
5. 进入「工作流」模块，配置截止提醒和状态变更通知等自动化规则。
6. 将项目表格分享给团队成员，设置合适的协作权限。
