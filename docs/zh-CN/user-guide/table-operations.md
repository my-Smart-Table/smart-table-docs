# 表格操作

本文档介绍 SmartTable 中的表格操作功能。

## 基础操作

### 创建表格

1. 点击左侧导航栏的 "+" 按钮
2. 选择 "新建表格"
3. 输入表格名称
4. 选择表格模板或自定义字段

### 删除表格

1. 右键点击表格名称
2. 选择 "删除表格"
3. 确认删除操作

### 重命名表格

1. 双击表格名称
2. 输入新名称
3. 按 Enter 键保存

## 高级操作

### 复制表格

可以复制整个表格，包括所有字段和数据。

### 导入数据

支持从 CSV、Excel 等格式导入数据。

### 导出数据

可以将表格数据导出为 CSV、Excel 等格式。
