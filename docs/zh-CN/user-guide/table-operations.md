# 表格操作

SmartTable 提供强大的表格操作功能，帮助您高效管理和组织数据。本章将介绍如何创建、编辑和管理数据表。

## 创建数据表

SmartTable 提供三种创建数据表的方式：

### 从模板创建

SmartTable 内置了多种常用模板，帮助您快速开始：

1. 点击左上角的 "+" 按钮
2. 选择"从模板创建"
3. 选择合适的模板（项目管理、客户关系、任务跟踪等）
4. 点击"使用模板"

### 从空白创建

如果您有特定的需求，可以从空白表开始：

1. 点击左上角的 "+" 按钮
2. 选择"创建空白表"
3. 输入数据表名称
4. 点击"创建"

### 导入数据

您可以从外部文件导入数据：

::: tip 支持的文件格式
- CSV 文件
- Excel 文件（.xlsx, .xls）
- JSON 文件
:::

1. 点击左上角的 "+" 按钮
2. 选择"导入数据"
3. 选择要导入的文件
4. 预览数据映射
5. 点击"开始导入"

## 表格基本操作

### 添加记录

向数据表添加新记录：

1. 点击表格底部的 "+" 按钮
2. 填写字段内容
3. 点击"保存"或按 Enter 键

**快捷键**：在最后一行按 `Ctrl + N`（Windows）或 `Cmd + N`（Mac）

### 编辑记录

编辑现有记录：

1. 点击要编辑的单元格
2. 修改内容
3. 点击其他位置或按 Enter 键保存

**提示**：所有修改都会自动保存到历史记录中，您可以随时撤销。

### 删除记录

删除不需要的记录：

1. 选中要删除的行
2. 右键点击，选择"删除"
3. 确认删除操作

**警告**：删除操作不可恢复，请谨慎操作。

### 排序和筛选

**排序**：

1. 点击列标题
2. 选择"升序排序"或"降序排序"
3. 表格数据自动重新排列

**筛选**：

1. 点击列标题的筛选图标
2. 选择筛选条件
3. 表格只显示符合条件的记录

## 高级操作

### 批量操作

对多条记录同时执行操作：

1. 按住 Shift 键选择多行
2. 右键点击，选择批量操作（复制、删除、移动等）

### 撤销和重做

SmartTable 记录所有操作历史：

- **撤销**：`Ctrl + Z`（Windows）或 `Cmd + Z`（Mac）
- **重做**：`Ctrl + Y`（Windows）或 `Cmd + Shift + Z`（Mac）

## 视图切换

SmartTable 支持多种视图方式：

- **表格视图**：以传统表格形式展示数据
- **看板视图**：以卡片形式展示任务流程
- **甘特图**：展示项目时间线和依赖关系
- **日历视图**：在日历上展示时间相关数据

点击右上角的视图切换按钮即可在不同视图之间切换。
