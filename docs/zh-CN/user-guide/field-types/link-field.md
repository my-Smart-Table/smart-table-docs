# 关联字段（Link）

关联字段用于建立两个数据表之间的关系，支持一对一、一对多和多对多三种关系模式。通过关联字段，可以实现跨表的数据联动、引用和汇总分析。

## 适用场景

- 项目表关联任务表：一个项目包含多个任务
- 客户表关联订单表：一个客户有多个订单
- 员工表关联部门表：多个员工属于一个部门
- 产品表关联供应商表：一个产品可由多个供应商提供

## 创建关联字段

1. 在数据表中点击「添加字段」。
2. 选择字段类型为「关联」。
3. 配置关联参数：
   - **目标表**：选择要关联的另一个数据表。
   - **关系类型**：选择一对一、一对多或多对多。
   - **显示字段**：选择在当前表中展示目标表的哪个字段值。
   - **双向关联**：是否在目标表中自动生成反向关联字段。
4. 点击保存。

## 关系类型

| 关系类型 | 说明 | 示例 |
| --- | --- | --- |
| 一对一 | 当前表一条记录仅关联目标表一条记录 | 员工 ↔ 工位 |
| 一对多 | 当前表一条记录可关联目标表多条记录 | 项目 → 多个任务 |
| 多对多 | 当前表和目标表记录可互相多对多关联 | 产品 ↔ 多个供应商 |

## 关联记录操作

### 添加关联

- 点击单元格中的「+」或搜索图标。
- 在弹出的记录选择器中搜索并勾选目标记录。
- 支持一次选择多条记录（一对多/多对多模式下）。

### 解除关联

- 将鼠标悬停在已关联记录标签上。
- 点击标签右侧的「×」即可解除关联。
- 解除关联不会删除目标表记录，仅断开关系。

### 查看关联记录详情

- 点击已关联记录标签，会弹出目标记录的详情抽屉。
- 在详情抽屉中可查看关联记录的全部字段，默认只读。

## 双向关联

开启双向关联后，SmartTable 会在目标表中自动创建一个指向当前表的反向关联字段。这样：

- 在 A 表中可以看到 B 表的关联记录。
- 在 B 表中也可以看到 A 表的关联记录。
- 任一方添加或解除关联，另一方会同步更新。

::: tip 建议
设计表结构时，建议对需要双向查看的关系开启双向关联，避免后续手动维护两个关联字段。
:::

## 与查找字段配合使用

关联字段通常与查找字段（Lookup）配合使用：

1. 先用关联字段建立表间关系。
2. 再用查找字段从关联记录中提取目标字段值。
3. 还可以对查找结果进行聚合（如求和、计数）。

## 注意事项

- 关联字段本身只存储记录 ID，不复制目标数据。
- 删除目标表记录后，关联字段中对应关联会自动消失。
- 修改关系类型可能会影响已有数据，请谨慎操作。
