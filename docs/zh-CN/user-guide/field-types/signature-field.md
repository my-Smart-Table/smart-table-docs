# 签字字段详解

签字（Signature）字段用于记录手写或电子化签名，广泛应用于合同签署、审批确认、收货签收、考勤打卡等需要"责任人留痕"的业务场景。签字完成后以 **PNG 图片** 形式存储为附件，支持在所有视图中以缩略图方式统一展示。

## 核心功能

- **两种签字模式**：手写签字（鼠标或触屏直接在 Canvas 上绘制）、输入签字（使用印刷体/手写体字体快速生成）。
- **高清 Canvas 渲染**：适配高 DPI 屏幕，笔画清晰锐利。
- **附件化存储**：签字生成的 PNG 图片作为附件上传，值为附件 ID（`attachment_id`），与附件字段共享后端存储服务。
- **多视图展示**：表格视图显示缩略图、看板卡片只读展示、详情抽屉支持编辑、表单视图支持录入、分享表单支持匿名提交。
- **安全删除**：删除签字前弹出二次确认，避免误操作；删除时同步清理后端附件。
- **筛选支持**：支持「为空」/「不为空」筛选操作符，方便按签字状态过滤记录。

## 使用方法

### 创建签字字段

在字段管理中点击「添加字段」，选择「签字」类型即可。签字字段**不支持设置默认值**（因为签字必须由真实操作产生）。

### 执行签字

在任何可编辑的视图中（表格、表单、详情抽屉、新增弹窗）：

1. 点击签字字段的「签字」按钮（首次）或已有缩略图上的「签字」图标（重新签字）。
2. 在弹出的签字面板中选择模式：
   - **手写签字**：用鼠标/手指在 Canvas 上直接书写。下方提供笔画粗细、颜色、背景色调整。
   - **输入签字**：在输入框中填写姓名，选择印刷体或手写体字体，实时预览。
3. 点击「清除」可重置当前签字，「取消」放弃本次操作，「保存」完成签字。

### 删除签字

在可编辑的视图中：

- 点击已有签字缩略图右上角的 🗑 删除图标，弹窗确认后清除。
- 删除后附件自动从后端清理，无法恢复。

### 在各视图中的表现

| 视图 | 表现 |
| --- | --- |
| 表格视图（VTable） | 渲染 32×32 缩略图，点击单元格打开签名面板 |
| 看板视图 | 卡片内只读展示缩略图（点击整块卡片打开详情抽屉） |
| 详情抽屉 | SignatureField 完整组件：缩略图 + 签字按钮 + 悬浮操作层 |
| 表单视图 | 同详情抽屉，支持直接签字保存 |
| 分享表单 | 同表单视图，匿名用户也可完成签字 |
| 画廊视图 | 以图片卡片展示 |

## 数据结构

签字字段在记录的 `values` 中以**字符串（附件 ID）**存储：

```json
{
  "手工签名": "att_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

该 ID 指向附件表中的一条 PNG 图片记录，可通过附件服务获取 Blob 下载或缩略图预览 URL。

## 后端校验

后端 `FieldService` 对签字字段做如下校验：

- **不可设默认值**：签字字段不允许配置默认值，校验失败返回 `字段 "xxx" 是签字字段，不支持默认值`。
- **值类型校验**：签名值必须为 `string | null`（附件 ID 或空），不接受其他类型。
- **附件生命周期**：签字更新时旧附件自动从存储中清理，避免垃圾文件堆积。

## 导入与导出

- **导入**：签字字段暂不支持通过 Excel/CSV 直接导入（因为签字图片无法从文本列还原）。
- **导出**：导出时签字字段输出为空值（或附件 ID，取决于导出格式），图片文件不随表格导出打包。如需签名原图，请逐个下载附件。

## 注意事项

1. **签字不可撤销**：点击保存后签字即生效。如需修改，请执行「重新签字」操作。
2. **存储空间**：每次签字生成一张 PNG 图片（通常几十 KB），占用附件存储额度。
3. **键盘保护**：签字字段**不监听全局 Delete/Backspace 按键**，避免与其他文本输入的删除行为冲突。
4. **匿名分享**：分享表单中提交的签字，在主应用中查看时会自动从后端下载图片（不依赖 IndexedDB 本地缓存）。
