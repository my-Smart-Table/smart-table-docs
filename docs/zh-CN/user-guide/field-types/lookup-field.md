# 查找字段（Lookup）

查找字段用于从关联记录中提取目标字段的值，并支持聚合计算。它是实现跨表数据联动和汇总分析的核心字段类型，通常与关联字段配合使用。

## 适用场景

- 在订单表中显示客户名称（从客户表查找）
- 在项目中汇总所有关联任务的完成数量
- 在产品表中计算供应商的平均报价
- 在销售表中统计每个客户的订单总金额

## 创建查找字段

1. 在数据表中点击「添加字段」。
2. 选择字段类型为「查找」。
3. 配置查找参数：
   - **源表**：选择已经建立关联的目标数据表。
   - **源字段**：选择要提取的目标字段。
   - **计算方式**：选择原值、去重、聚合等计算方式。
   - **筛选条件**（可选）：只查找满足条件的关联记录。
4. 点击保存。

## 计算方式

| 计算方式 | 说明 |
| --- | --- |
| 原值 | 直接显示关联记录的目标字段值，一对多时显示为列表 |
| 去重 | 对多个关联记录的值去重后显示 |
| 去重计数 | 去重后的唯一值数量 |
| 求和 | 对数值字段求和 |
| 计数 | 统计关联记录数量 |
| 平均值 | 对数值字段求平均 |
| 最大值 | 取字段最大值（支持数字和日期） |
| 最小值 | 取字段最小值（支持数字和日期） |

## 筛选条件

查找字段支持对关联记录设置筛选条件：

- 支持按源表字段设置多条件筛选。
- 支持 AND / OR 组合逻辑。
- 支持 20+ 种运算符（等于、不等于、包含、为空等）。
- 设置筛选后，只有满足条件的关联记录才会参与计算。

### 条件值的来源

配置筛选条件时，条件值支持三种来源：

| 值类型 | 说明 |
| --- | --- |
| 当前表字段 | 与当前表（本表）某个字段的值比较 |
| 自定义值 | 与手工录入的固定值比较 |
| 当前记录 | 与当前记录本身比较。**仅当所选源表字段为关联字段时可选** |

::: tip 关联字段的匹配规则
关联字段在记录中存储的是**目标表的记录 ID**（单个 ID 或 ID 数组），而不是显示值。因此：

- 要用「源表的关联字段」匹配「当前这条记录」时，把值类型选为**「当前记录」**即可。
- 若值类型选择「当前表字段」并指定了一个文本字段（如项目名称），系统会自动把该显示值解析为对应的记录 ID 后再比较。
- 关联字段的「等于」按记录 ID 交集判断：只要源记录的关联值中包含目标记录 ID 即视为命中。
:::

## 典型示例：按项目汇总任务工时

**场景**：A 表为「项目」，B 表为「任务」，B 表通过关联字段「所属项目」指向 A 表。现在需要在 A 表中统计每个项目下所有任务的工时合计。

**配置步骤**：

1. 在 A 表点击「添加字段」，选择字段类型「查找」。
2. **源表**：选择 B 表（任务）。
3. **引用字段**：选择 B 表的「工时」字段。
4. **筛选条件**：字段选择 B 表的「所属项目」，操作符选择「等于」，值类型选择**「当前记录」**。
5. **计算方式**：选择「求和」。
6. 点击保存。

配置完成后，A 表每一行项目记录都会汇总「所属项目」指向自己的那些任务的工时。

::: warning 常见误区
不要直接用「所属项目 = 项目名称」这类配置。B 表的「所属项目」存的是 A 表的记录 ID，而「项目名称」是文本，两者直接比较永远不会相等，会导致汇总结果为空。请改用「当前记录」。
:::

## 字段格式化

对于非原值/去重模式，查找字段支持自定义结果格式：

| 格式类型 | 适用场景 |
| --- | --- |
| 数字 | 聚合结果为数字，可配置小数位数 |
| 货币 | 显示货币符号，如 ¥ |
| 百分比 | 显示百分比 |
| 日期 | 最大值/最小值为日期时，可配置日期格式 |

原值和去重模式下，查找结果会跟随源字段的原始类型渲染（如附件显示缩略图、成员显示头像、单选显示彩色标签等）。

## 预览功能

在配置查找字段时，如果当前记录已有关联数据，可以实时预览计算结果，方便确认配置是否正确。

## 与关联字段的关系

查找字段通常与关联字段配合使用，但源表并不强制要求当前表已创建关联字段：

- 源表可以是同一数据基础（Base）下的任意其他数据表。
- 用法一：当前表存在指向源表的关联字段时，用筛选条件（值类型「当前表字段」）限定范围。
- 用法二：源表通过关联字段指回当前表时，用筛选条件的「当前记录」值类型实现反向汇总（见「典型示例：按项目汇总任务工时」）。
- 一个关联字段可以被多个查找字段引用。
- 删除源表中被引用或用于筛选的字段后，依赖它的查找字段会失效。

## 使用建议

- 需要简单引用时使用「原值」模式。
- 一对多关系需要汇总统计时，使用「求和」「计数」「平均值」等聚合模式。
- 需要排除部分关联记录时，添加筛选条件。
- 源表通过关联字段指回本表（如任务表关联项目表）时，筛选条件的值类型使用「当前记录」。
- 聚合结果为空时，优先检查筛选条件是否命中：可先用「计数」验证筛选结果，再切换为「求和」等数值聚合。
