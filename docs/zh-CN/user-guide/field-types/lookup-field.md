# 查找字段（Lookup）

查找字段用于从关联记录中提取目标字段的值，并支持聚合计算。它是实现跨表数据联动和汇总分析的核心字段类型，通常与关联字段配合使用。

## 适用场景

- 在订单表中显示客户名称（从客户表查找）
- 在项目中汇总所有关联任务的完成数量
- 在产品表中计算供应商的平均报价
- 在销售表中统计每个客户的订单总金额

## 创建查找字段

1. 在数据表中点击「添加字段」。
2. 选择字段类型为「查找」。
3. 配置查找参数：
   - **源表**：选择已经建立关联的目标数据表。
   - **源字段**：选择要提取的目标字段。
   - **计算方式**：选择原值、去重、聚合等计算方式。
   - **筛选条件**（可选）：只查找满足条件的关联记录。
4. 点击保存。

## 计算方式

| 计算方式 | 说明 |
| --- | --- |
| 原值 | 直接显示关联记录的目标字段值，一对多时显示为列表 |
| 去重 | 对多个关联记录的值去重后显示 |
| 去重计数 | 去重后的唯一值数量 |
| 求和 | 对数值字段求和 |
| 计数 | 统计关联记录数量 |
| 平均值 | 对数值字段求平均 |
| 最大值 | 取字段最大值（支持数字和日期） |
| 最小值 | 取字段最小值（支持数字和日期） |

## 筛选条件

查找字段支持对关联记录设置筛选条件：

- 支持按源表字段设置多条件筛选。
- 支持 AND / OR 组合逻辑。
- 支持 20+ 种运算符（等于、不等于、包含、为空等）。
- 设置筛选后，只有满足条件的关联记录才会参与计算。

## 字段格式化

对于非原值/去重模式，查找字段支持自定义结果格式：

| 格式类型 | 适用场景 |
| --- | --- |
| 数字 | 聚合结果为数字，可配置小数位数 |
| 货币 | 显示货币符号，如 ¥ |
| 百分比 | 显示百分比 |
| 日期 | 最大值/最小值为日期时，可配置日期格式 |

原值和去重模式下，查找结果会跟随源字段的原始类型渲染（如附件显示缩略图、成员显示头像、单选显示彩色标签等）。

## 预览功能

在配置查找字段时，如果当前记录已有关联数据，可以实时预览计算结果，方便确认配置是否正确。

## 与关联字段的关系

查找字段依赖关联字段：

- 必须先创建关联字段，才能选择对应的源表。
- 一个关联字段可以被多个查找字段引用。
- 删除关联字段后，依赖它的查找字段会失效。

## 使用建议

- 需要简单引用时使用「原值」模式。
- 一对多关系需要汇总统计时，使用「求和」「计数」「平均值」等聚合模式。
- 需要排除部分关联记录时，添加筛选条件。
