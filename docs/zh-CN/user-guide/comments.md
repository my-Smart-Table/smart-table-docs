# 评论与 @提及 使用手册

## 1. 功能概述

记录评论让团队可以直接在某条记录上展开讨论，无需切换到外部工具。你可以发表评论、回复他人、使用 `@` 提及相关成员，并关注重要记录以接收更新提醒。

**适用场景**：数据校对、需求确认、跨部门跟进、审批意见收集等。

**入口**：打开任意记录的详情抽屉，点击顶部的「评论」页签。

## 2. 打开评论区

1. 在表格视图中点击目标记录，打开右侧的「记录详情」抽屉。
2. 抽屉顶部为页签栏，点击「评论」页签即可进入评论区。
3. 页签栏右侧为「历史」与「关注」按钮，可分别查看记录变更历史、关注 / 取消关注当前记录。

## 3. 发表评论

1. 在「评论」页签底部的输入框中输入内容。
2. 点击「发送」。
3. 评论将按时间顺序显示在评论列表中，回复会内联展示在对应评论的下方。

> 「查看者」角色没有评论输入框，仅可查看评论。

## 4. 回复评论

1. 在任意评论下方点击「回复」。
2. 输入框进入回复状态，并提示正在回复的对象。
3. 输入内容后点击「发送」，回复将内联展示在被回复评论的下方。
4. 被回复的评论作者会收到一条回复通知。

## 5. @提及成员

1. 在输入框中输入 `@`，随后会弹出可提及的成员列表（即可访问该记录的 Base 成员与表分享成员）。
2. 继续输入名称可过滤列表，点击选中成员，内容中会插入 `@成员名称`。
3. 发送后，被提及的成员会收到 @提及通知（站内信 + 邮件）。

> 只能提及能够访问该记录的成员；@ 自己不产生通知。

## 6. 编辑与删除评论

- **编辑**：在自己的评论旁点击「编辑」，修改后保存。
- **删除**：在自己的评论旁点击「删除」，确认后删除。
  - 无回复的评论将直接删除。
  - 含有回复的评论会保留占位（显示「评论已删除」），以维持讨论上下文。
- **编辑者及以上角色**可删除任意成员的评论。

## 7. 关注记录

1. 在记录详情抽屉顶部页签栏右侧，点击「关注」按钮。
2. 关注后按钮变为「已关注」；再次点击可取消关注。
3. 你关注的记录在产生新评论时，你会收到「记录有新评论」通知。

## 8. 通知与偏好

评论相关通知默认全部开启，可在个人「通知设置」中分别关闭：

- 被 @提及时通知
- 被回复时通知
- 记录有新评论时通知

通知先写入站内消息（界面消息中心），若部署了邮件服务则同时发送邮件。详见《[站内信通知](/zh-CN/user-guide/notification.html)》。

## 9. 权限说明

| 操作 | 所有者 / 管理员 / 编辑者 | 评论者 | 查看者 |
| --- | :---: | :---: | :---: |
| 查看评论 | ✅ | ✅ | ✅ |
| 发表评论 / 回复 | ✅ | ✅ | — |
| @提及成员 | ✅ | ✅ | — |
| 编辑 / 删除自己的评论 | ✅ | ✅ | — |
| 删除任意评论 | ✅ | — | — |
| 关注记录 | ✅ | ✅ | ✅ |

> 通过数据表分享加入的用户，按加入时获得的角色（编辑者 / 评论者 / 查看者）享有对应权限。

## 10. 常见问题

- **为什么看不到评论输入框？**
  你的角色为「查看者」，或通过分享加入时以查看者身份加入，此时仅可查看评论。

- **@某人没有反应 / 搜不到？**
  只能提及能访问该记录的成员，请确认对方已加入该 Base 或被分享了该数据表。

- **删除的评论不见了？**
  无回复的评论会直接删除；含有回复的评论会显示为「评论已删除」占位，以保留讨论上下文。

- **如何关闭评论通知？**
  在个人「通知设置」中关闭对应偏好即可，站内信与邮件会一并停止发送。
