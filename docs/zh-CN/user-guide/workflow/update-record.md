# 更新记录节点

更新记录节点用于在工作流执行过程中，自动修改已有记录的字段值。通常用于根据业务规则更新状态、标记、时间戳等。

## 适用场景

- 审批通过后自动将状态更新为「已通过」
- 任务逾期时自动标记为「已逾期」
- 订单发货后更新发货时间
- 满足条件后自动给记录打标签

## 配置项

### 更新对象

更新记录节点默认更新触发记录，也可以通过表达式指定其他记录 ID。

### 字段更新映射

配置要更新的字段及其新值：

| 配置项 | 说明 |
| --- | --- |
| 字段 | 要更新的目标字段 |
| 值模板 | 静态值或引用表达式 |

### 静态值

直接输入固定值，例如：

- 状态 = "已完成"
- 处理时间 = `2026-07-28`
- 是否归档 = true

### 引用表达式

通过 `{{}}` 引用上下文变量：

```
{{trigger.record.<字段ID>}}
{{node_<节点ID>.<字段ID>}}
{{loop.current_data.<字段ID>}}
```

## 使用示例

### 示例：任务完成后更新项目进度

| 字段 | 值模板 |
| --- | --- |
| 状态 | 静态值：已完成 |
| 完成时间 | `{{NOW}}` |
| 完成人 | `{{trigger.record.updated_by}}` |

## 注意事项

- 默认更新触发记录，如要更新其他记录需提供正确的记录 ID。
- 系统字段（如创建人、创建时间）通常不可更新。
- 更新操作会触发记录更新事件，如工作流配置了记录更新触发器，需注意避免循环触发。
