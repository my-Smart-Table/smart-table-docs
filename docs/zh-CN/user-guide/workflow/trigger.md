# 触发器

触发器是工作流的入口，决定工作流何时启动。每个工作流有且仅有一个触发器节点，位于画布的起始位置。

## 触发器类型

<img src="/images/user-guide/basic-features/workflow/workflow-overview.png" alt="工作流触发器" style="max-width: 100%; border: 1px solid #e0e0e0; border-radius: 4px;">

SmartTable 支持以下触发器类型：

| 触发器类型 | 说明 |
| --- | --- |
| 记录创建时 | 新记录创建时触发 |
| 记录更新时 | 记录更新时触发，可监听指定字段 |
| 指定时间 | 按设定的时间计划触发，支持重复 |
| 到达记录中的时间时 | 当记录中的日期/日期时间字段到达指定时间时触发 |

## 记录创建触发器

当关联数据表中有新记录创建时，工作流自动启动。

### 配置项

- **触发表**：选择要监听的数据表。
- **过滤条件**：满足条件时才触发，不配置则全局触发。
- **条件组合**：支持 AND（全部满足）或 OR（任一满足）。

### 使用场景

- 新订单创建后自动发送通知
- 新任务创建后自动分配负责人
- 新客户录入后自动发送欢迎邮件

## 记录更新触发器

当关联数据表中已有记录被更新时触发。

### 配置项

- **监听字段**：选择要监听的字段。不选择则任何字段更新都触发。
- **过滤条件**：满足条件时才触发，不配置则全局触发。

### 使用场景

- 任务状态变为「已完成」时通知项目经理
- 订单金额修改时记录变更日志
- 优先级提升时触发加急流程

## 指定时间触发器

按预定的时间计划触发工作流，不依赖记录变更。

### 配置项

- **开始日期**：首次触发的日期。
- **开始时间**：首次触发的时间。
- **重复类型**：
  - 不重复：只触发一次
  - 每日：每天同一时间触发
  - 每周：每周指定日期触发
  - 每月：每月指定日期触发
  - 每年：每年指定日期触发
  - 工作日：每周一至周五触发
  - 自定义：按自定义间隔触发（如每 3 天、每 2 周）
- **截止日期**：设置后，到达截止日期不再重复触发。
- **时区**：按本地时区解释触发时间。

### 使用场景

- 每日生成数据报表
- 每周发送周报提醒
- 每月初自动创建月度任务

## 到达记录中的时间时

当记录中某个日期/日期时间字段的值到达时触发。

### 配置项

- **时间字段**：选择记录中的日期或日期时间字段。
- **过滤条件**：满足条件时才触发。

### 使用场景

- 任务到期前一天提醒
- 合同到期前 7 天通知
- 会议开始前 30 分钟提醒

## 过滤条件

除指定时间触发器外，其他触发器都支持配置过滤条件：

- 选择字段和运算符（等于、不等于、包含、为空等）。
- 支持多个条件组合。
- 支持 AND / OR 逻辑。

::: tip 性能建议
尽量使用索引字段（如主键、单选、日期）作为过滤条件，避免在大数据表上使用全文匹配字段。
:::

## 触发记录变量

触发后，当前触发记录的信息会注入到工作流上下文中，后续节点可通过变量引用：

```
{{trigger.record.<字段ID>}}
```
