# 发送邮件节点

发送邮件节点用于在工作流执行过程中自动发送邮件通知。支持自定义收件人、主题、正文，也可以选择系统预设的邮件模板。

## 适用场景

- 新订单创建后给客户发送确认邮件
- 任务截止前发送提醒邮件
- 审批通过后通知相关人员
- 每日/每周发送数据报告

## 前置条件

使用发送邮件节点前，需要管理员在系统配置中完成邮件服务配置：

- 启用邮件服务
- 配置 SMTP 服务器、端口、账号、密码
- 配置发件人邮箱和加密方式
- 发送测试邮件验证配置是否正确

## 配置项

### 收件人

支持两种收件人来源：

| 类型 | 说明 |
| --- | --- |
| 字段 | 从记录中的邮箱字段或成员字段获取收件人 |
| 固定 | 手动输入一个或多个固定邮箱地址 |

### 邮件主题

支持静态文本和变量引用：

```
您有一个新任务：{{trigger.record.task_name}}
```

### 邮件正文

支持两种内容模式：

| 模式 | 说明 |
| --- | --- |
| 自定义 | 手动编写邮件正文，支持变量引用 |
| 模板 | 选择系统管理员预设的邮件模板 |

### 自定义正文示例

```
您好，{{trigger.record.customer_name}}：

您的订单 {{trigger.record.order_no}} 已创建，总金额 {{trigger.record.amount}} 元。

详情请登录系统查看。
```

### 可用变量

- `{{trigger.record.<字段ID>}}`：触发记录字段
- `{{node_<节点ID>.record.<字段ID>}}`：前置节点记录字段
- `{{loop.current_data.<字段ID>}}`：循环节点当前数据

## 邮件模板

如果选择「模板」模式，可以从系统预设模板中选择：

- 注册验证邮件
- 密码重置邮件
- 通知邮件
- 自定义模板

模板内容由管理员在系统后台维护。

## 注意事项

- 邮件发送是异步执行的，可能会有短暂延迟。
- 如果 SMTP 配置不正确，邮件会进入失败状态并记录错误信息。
- 收件人地址需要是有效的邮箱格式。
- 频繁发送大量邮件时，建议配置邮件队列和重试策略。
