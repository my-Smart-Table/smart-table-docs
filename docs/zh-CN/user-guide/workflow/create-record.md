# 创建记录节点

创建记录节点用于在工作流执行过程中，在指定的目标数据表中自动创建一条或多条新记录。常用于根据触发记录的信息生成关联数据。

## 适用场景

- 新订单创建时，自动在「发货单」表中生成发货记录
- 新任务创建时，自动在「子任务」表中创建默认子任务
- 客户状态变为「签约」时，自动在「合同」表中创建合同记录

## 配置项

### 目标表

选择要在其中创建记录的数据表。可以选择当前 Base 下的任意数据表。

### 字段映射

配置目标表字段的值来源。每行映射包含：

| 配置项 | 说明 |
| --- | --- |
| 目标字段 | 目标表中要写入值的字段 |
| 值来源 | 静态值 或 表达式/字段引用 |

### 静态值

直接输入固定值。适用于不需要动态变化的字段，例如：

- 状态 = "待处理"
- 是否通知 = true
- 默认值 = "系统自动创建"

### 引用表达式

通过 `{{}}` 语法引用触发记录或其他节点的结果，例如：

```
{{trigger.record.customer_name}}
```

支持的上下文变量包括：

- `{{trigger.record.<字段ID>}}`：触发记录字段
- `{{node_<节点ID>.record.<字段ID>}}`：前置节点产生的记录字段
- `{{loop.current_data.<字段ID>}}`：循环节点当前迭代数据

## 使用示例

### 示例：新订单自动生成发货单

| 目标字段 | 值来源 |
| --- | --- |
| 订单编号 | `{{trigger.record.order_no}}` |
| 收货人 | `{{trigger.record.customer_name}}` |
| 状态 | 静态值：待发货 |
| 创建时间 | `{{NOW}}` |

## 注意事项

- 目标表必须存在且有写入权限。
- 必填字段需要配置映射，否则创建会失败。
- 关联字段可以通过引用表达式写入目标记录 ID。
- 创建记录节点支持在循环体内使用，配合循环实现批量创建。
