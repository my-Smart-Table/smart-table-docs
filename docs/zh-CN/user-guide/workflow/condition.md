# 条件节点

条件节点用于在工作流中根据条件判断走不同分支，实现复杂的业务逻辑控制。每个条件节点可以包含多个分支，系统会按顺序匹配分支条件，第一个匹配的分支会被执行。

## 适用场景

- 根据订单金额决定审批流程
- 根据任务优先级选择通知方式
- 根据客户类型分配不同销售人员
- 判断记录是否满足某些条件后再执行后续操作

### 分支

每个条件节点包含一个或多个分支：

| 配置项 | 说明 |
| --- | --- |
| 分支名称 | 便于识别的分支名称 |
| 条件组合 | AND（全部满足）或 OR（任一满足） |
| 条件列表 | 具体的字段、运算符、值 |

### 默认分支

当所有条件分支都不匹配时，会执行默认分支（如果已配置）。默认分支不需要设置条件。

::: tip 建议
为条件节点配置默认分支，可以避免所有条件都不满足时工作流中断。
:::

### 条件设置

每个条件包含：

- **字段**：选择当前记录或前置节点结果中的字段。
- **运算符**：等于、不等于、大于、小于、包含、为空等。
- **值**：静态值或引用表达式。

### 条件组合

- **全部满足（AND）**：所有条件都满足时才命中该分支。
- **任一满足（OR）**：任一条件满足时即命中该分支。

## 执行逻辑

1. 工作流执行到条件节点时，按分支顺序依次判断。
2. 命中某个分支后，执行该分支后续的节点。
3. 如果未命中任何分支且没有默认分支，条件节点后的流程将终止。

## 使用示例

### 示例：根据订单金额分支

| 分支名称 | 条件 |
| --- | --- |
| 大额订单 | 金额 > 100000 |
| 中额订单 | 金额 > 10000 且 金额 <= 100000 |
| 小额订单 | 默认分支 |

后续可以为大额订单添加额外的审批节点，为中额订单发送普通通知。

## 注意事项

- 条件节点不支持放在循环体内。
- 分支顺序很重要，系统按从上到下的顺序匹配。
- 条件值的数据类型要与字段类型匹配。
