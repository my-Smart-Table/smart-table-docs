# 查找记录节点

查找记录节点用于在工作流中查询目标数据表中的记录，并将查询结果保存到变量中，供后续节点使用。它是实现动态数据查询和批量处理的关键节点。

## 适用场景

- 查询某个客户的所有订单
- 查找状态为「待处理」的任务列表
- 获取满足条件的目标记录，用于后续更新或通知
- 为循环节点提供数据源

### 目标表

选择要查询的数据表。

### 查询条件

配置过滤条件来筛选记录：

- 选择字段、运算符和值。
- 支持多个条件组合。
- 支持 AND / OR 逻辑。
- 值支持静态值和引用表达式。

### 排序

- **排序字段**：选择按哪个字段排序。
- **排序方向**：升序或降序。

### 限制数量

设置返回记录的最大数量，范围 1 ~ 1000，默认 100。

### 结果变量名

为查询结果指定变量名，默认 `records`。后续节点可通过变量名引用结果：

```
{{find_records.records}}
```

具体字段引用：

```
{{find_records.records[0].<字段ID>}}
```

### 空结果处理

- **继续**：未查到记录时继续执行后续节点。
- **停止**：未查到记录时终止工作流。

## 使用示例

### 示例：查找客户的未处理订单

| 配置项 | 值 |
| --- | --- |
| 目标表 | 订单表 |
| 条件 1 | 客户ID = `{{trigger.record.customer_id}}` |
| 条件 2 | 状态 = "待处理" |
| 排序 | 创建时间 降序 |
| 限制数量 | 50 |
| 结果变量名 | pending_orders |

后续节点可以通过 `{{find_records.pending_orders}}` 引用查询结果。

## 与循环节点配合使用

查找记录节点常作为循环节点的数据源：

1. 查找记录节点查询出一批记录。
2. 循环节点选择「查找记录结果」作为数据源。
3. 循环体内对每个记录执行创建、更新、发送邮件等操作。

## 注意事项

- 查询条件中的字段值支持表达式，但需确保表达式返回正确的数据类型。
- 返回结果过多可能影响性能，建议合理设置限制数量。
- 在循环体中也可使用查找记录节点，但需注意避免嵌套过深。
