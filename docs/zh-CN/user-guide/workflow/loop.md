# 循环节点

循环节点用于对一组数据进行迭代处理，适合批量操作场景。循环体内可以嵌套创建记录、更新记录、查找记录、发送邮件、Webhook 等节点。

## 适用场景

- 批量创建子任务
- 给多个客户发送通知邮件
- 批量更新满足条件的记录
- 遍历查找记录结果并逐个处理

### 数据源类型

循环节点支持以下几种数据源：

| 数据源类型 | 说明 |
| --- | --- |
| 查找记录结果 | 迭代前置查找记录节点的全部结果 |
| 查找记录列 | 迭代前置查找记录节点中某个字段的多个值 |
| 触发器字段 | 迭代触发记录中的人员、多选、关联或附件字段 |
| Webhook 数组 | 迭代前置 Webhook 节点返回的数组数据 |

### 最大循环次数

限制循环的最大迭代次数，范围 1 ~ 1000，默认 100。超过最大次数后循环会自动停止。

### 错误处理

- **跳过**：某次迭代执行失败时，跳过该次继续下一次。
- **终止**：某次迭代执行失败时，终止整个循环。

### 空结果处理

- **跳过循环**：数据源为空时跳过循环节点。
- **报错**：数据源为空时工作流报错。

## 循环体

循环体是循环节点内部的子节点列表，每次迭代都会按顺序执行循环体内的节点。

### 循环体内可用节点

- 创建记录
- 更新记录
- 查找记录
- 发送邮件
- Webhook
- 循环（支持嵌套）

### 循环体内不可用节点

- 条件节点
- 触发器

## 循环变量

循环执行时，以下变量会注入到上下文中，可在循环体内的节点中使用：

| 变量 | 说明 |
| --- | --- |
| `{{loop.current_data}}` | 当前迭代的数据对象 |
| `{{loop.index}}` | 当前迭代的索引（从 0 开始） |
| `{{loop.round}}` | 当前迭代的轮次（从 1 开始） |
| `{{loop.total}}` | 数据总数 |

示例：

```
{{loop.current_data.customer_name}}
{{loop.current_data[0].field_id}}
```

## 循环限制

- 单个工作流最多包含 5 个循环节点。
- 循环最大嵌套深度为 3 层。
- 循环体内可以再次使用循环节点，但需注意性能和逻辑复杂度。

## 使用示例

### 示例：批量给订单客户发送邮件

1. 查找记录节点：查询状态为「待发货」的订单，结果变量为 `orders`。
2. 循环节点：数据源选择「查找记录结果 - orders」。
3. 循环体内添加发送邮件节点：
   - 收件人：`{{loop.current_data.customer_email}}`
   - 主题：`您的订单 {{loop.current_data.order_no}} 已发货`

## 注意事项

- 循环数据源为空时，根据配置会跳过或报错。
- 循环体内避免引用循环外的节点结果，除非逻辑上确实需要。
- 大量数据循环时，建议合理设置最大循环次数，避免超时。
