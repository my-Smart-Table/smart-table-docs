# 表格视图

表格视图是 SmartTable 最基础的视图类型，提供了类似电子表格的数据展示方式。

## 功能特性

### 排序

- 点击列头进行排序
- 支持升序/降序切换
- 支持多列排序

### 筛选

- 快速筛选：点击列头的筛选图标
- 高级筛选：设置多个筛选条件
- 支持条件组合（AND/OR）

### 分组

- 按字段值分组显示
- 支持多级分组
- 分组折叠/展开

### 冻结列

- 冻结左侧列
- 冻结右侧列
- 方便查看大表格

## 行操作

### 添加行

- 点击表格底部 "+" 按钮
- 使用快捷键 `Ctrl + N`

### 删除行

- 选中行后右键选择 "删除"
- 使用快捷键 `Delete`

### 移动行

- 拖拽行到目标位置
- 支持批量移动

## 列操作

### 调整列宽

- 拖拽列边缘调整宽度
- 双击自动调整列宽

### 隐藏/显示列

- 右键列头选择 "隐藏列"
- 在视图设置中重新显示

### 移动列

- 拖拽列头到目标位置
