# 看板视图

看板视图以卡片和列的形式展示数据，适合流程管理和任务跟踪。您可以通过拖拽卡片在不同状态列之间移动，直观地反映工作进展。

## 功能特性

### 看板列

- 通常根据一个「单选」字段（如状态）自动创建列。
- 支持自定义列名称和顺序。
- 可拖拽调整列的左右顺序。

### 卡片管理

- 每张卡片代表一条记录。
- 卡片上可显示关键字段，如标题、负责人、截止日期、优先级等。
- 支持在看板中直接快速编辑字段值。
- 拖拽卡片到不同列即可更新对应字段值。

### 筛选与分组

- 支持按条件筛选卡片，快速聚焦重点任务。
- 可配置分组方式，进一步组织卡片。

## 配置看板视图

1. 创建或切换到看板视图。
2. 选择用于分组的字段（通常为状态、阶段等单选字段）。
3. 配置卡片上需要显示的字段。
4. 调整列顺序和卡片排序规则。

## 使用场景

看板视图特别适合以下场景：

- **项目管理**：按「待办 / 进行中 / 已完成」跟踪任务状态。
- **任务跟踪**：直观查看每个任务的负责人和进度。
- **销售流程**：管理潜在客户从线索到成交的各个阶段。
- **问题跟踪**：按问题状态（待处理 / 处理中 / 已解决）组织缺陷。

::: tip 拖拽更新状态
在看板视图中，直接将卡片从一列拖到另一列，系统会自动更新该记录的分组字段值，无需进入编辑模式。
:::
