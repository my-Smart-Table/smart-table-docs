# 看板视图

看板视图是一种直观的任务管理视图，适合流程管理和任务跟踪。

## 功能特性

### 看板列

- 根据选择字段自动创建列
- 支持自定义列名称
- 可以拖拽调整列顺序

### 卡片管理

- 拖拽卡片在列之间移动
- 卡片显示关键字段
- 支持快速编辑

### 筛选与分组

- 按条件筛选卡片
- 支持分组显示

## 使用场景

- 项目管理
- 任务跟踪
- 销售流程
- 问题跟踪
