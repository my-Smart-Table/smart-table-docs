# 甘特图

甘特图是项目管理中常用的视图，用于展示项目进度和时间线。

## 功能特性

### 时间轴显示

- 横轴为时间轴
- 纵轴为任务列表
- 任务条显示起止时间

### 任务管理

- 设置开始和结束时间
- 设置任务依赖关系
- 拖拽调整任务时间

### 进度跟踪

- 显示任务完成进度
- 今日线标记当前日期
- 逾期任务高亮显示

## 使用场景

- 项目计划
- 进度跟踪
- 资源分配
- 时间管理
