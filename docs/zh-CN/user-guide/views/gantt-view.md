# 甘特图

甘特图视图以时间轴的方式展示任务或项目进度，横轴为时间，纵轴为任务列表，适合项目计划、进度跟踪和资源调度。

## 功能特性

### 时间轴显示

- 横轴展示时间刻度（日、周、月等）。
- 纵轴展示任务列表。
- 每个任务以条形显示开始时间、结束时间和持续时长。

### 任务管理

- 设置任务的开始时间和结束时间。
- 配置任务之间的依赖关系。
- 拖拽任务条可调整起止时间。
- 拉伸任务条边缘可调整持续时长。

### 进度跟踪

- 任务条显示完成进度。
- 当前日期线（今日线）高亮显示。
- 逾期任务自动高亮，方便识别风险。

## 配置甘特图视图

<img src="/images/user-guide/basic-features/views/views-gantt-view.png" alt="甘特图视图" style="max-width: 100%; border: 1px solid #e0e0e0; border-radius: 4px;">

1. 创建或切换到甘特图视图。
2. 选择作为「任务名称」的字段。
3. 选择「开始日期」和「结束日期」字段。
4. （可选）选择「进度」字段，用于显示任务完成百分比。
5. （可选）配置任务依赖关系。

## 使用场景

甘特图视图适合以下场景：

- **项目计划**：制定项目整体时间计划和里程碑。
- **进度跟踪**：直观查看各任务的实际进度与计划对比。
- **资源分配**：了解任务分布，合理安排资源。
- **时间管理**：识别关键路径和潜在延期风险。

::: tip 与表格视图配合
建议在甘特图视图中管理时间计划，同时在表格视图中维护详细的字段信息，两者互为补充。
:::
