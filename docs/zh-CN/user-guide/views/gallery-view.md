# 画册视图

画册视图以卡片形式展示记录，每张卡片可显示图片封面和标题，非常适合展示带有附件或图片的数据，如产品目录、素材库、人员信息等。

## 适用场景

- 产品目录展示（封面图 + 产品名称）
- 图片素材库管理
- 人员信息卡片
- 作品集或案例展示

## 创建画册视图

1. 在视图切换器中点击「+ 新建视图」。
2. 选择「画册」视图类型。
3. 输入视图名称，点击创建。

## 配置画册视图

### 封面字段

- 画册视图会自动识别数据表中的**附件字段**作为封面来源。
- 如果存在多个附件字段，可在视图设置中选择使用哪一个字段作为封面。
- 只显示包含图片附件的记录；没有图片的记录会显示为无封面卡片。

### 标题字段

- 默认使用数据表的**主键字段**作为卡片标题。
- 支持选择以下类型的字段作为标题：
  - 单行文本
  - 数字
  - 单选
  - 公式
- 公式字段会实时计算并显示结果。

## 卡片操作

### 查看图片

- 点击卡片封面图片，可打开图片预览器。
- 支持多张图片左右切换查看。

### 编辑记录

- 点击卡片非图片区域，可打开记录详情抽屉进行编辑。
- 点击卡片上的编辑图标，也可快速进入编辑模式。

### 删除记录

- 点击卡片上的删除图标，确认后可删除该记录。

## 实时协作

画册视图支持实时协作能力：

- 当其他用户新增、修改或删除记录时，画册会自动同步更新。
- 支持离线恢复后重放数据变更。

## 视图配置项

| 配置项 | 说明 |
| --- | --- |
| 封面字段 | 选择附件字段作为卡片封面 |
| 标题字段 | 选择用于显示卡片标题的字段 |
| 筛选 | 按条件过滤展示的记录 |
| 排序 | 按字段排序卡片顺序 |

::: tip 封面显示建议
为获得最佳展示效果，建议为画册视图单独创建一个附件字段，并上传宽高比例统一的图片。
:::
