# 日历视图

日历视图以日历形式展示数据，适合管理时间相关的内容，如会议、活动、任务截止日期等。

## 功能特性

### 日历显示

- 支持月视图、周视图和日视图切换。
- 记录按日期字段显示在对应日期格中。
- 支持拖拽记录调整日期。

### 事件管理

- 点击日期格可直接创建新记录。
- 拖拽记录到不同日期，自动更新日期字段。
- 支持时间范围显示，适合跨天事件。

## 配置日历视图

1. 创建或切换到日历视图。
2. 选择作为日期依据的字段（日期或日期时间字段）。
3. 配置卡片上显示的字段（如标题、状态、负责人等）。
4. 选择默认视图模式（月/周/日）。

## 使用场景

日历视图适合以下场景：

- **会议安排**：在日历上查看和管理会议日程。
- **日程管理**：个人或团队日程一览。
- **活动计划**：活动、发布、上线等关键节点的可视化。
- **截止日期跟踪**：跟踪任务、项目的截止日期和里程碑。

::: tip 快速调整日期
在日历视图中直接拖拽事件到新的日期，即可更新记录的日期字段，无需打开编辑面板。
:::
