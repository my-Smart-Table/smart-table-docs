欢迎使用 SmartTable！本指南将帮助您快速上手。

下载最新 release 版本下的一键启动包，解压之后一键启动：

> 默认账号邮箱和默认密码获取方式：关注官方微信公众号，私信回复：'SmartTable'，即可获取。

```bash
# Windows PowerShell
.\start.bat

# Linux/macOS
./start.sh
```

> 该一键启动包无需依赖任何外部环境，双击即可启动。
>
> **无需安装任何依赖，无需手工创建账号。**
>
> 启动后会自动打开浏览器，然后使用默认的账号邮箱和密码登录即可试用。

## Docker 启动

使用官方 docker 镜像启动（自动适配架构）：

> 默认账号邮箱和默认密码获取方式：关注官方微信公众号，私信回复：'SmartTable'，即可获取。

```bash
docker run -d \
  --name smarttable \
  -p 80:80 \
  -v smarttable_data:/app/data \
  -v smarttable_uploads:/app/uploads \
  -v smarttable_redis:/data/redis \
  ygbinac/smarttable:latest
```

或者使用 docker compose，只需创建以下 `docker-compose.yml`：

```yaml
services:

## 用户认证

### 注册账号

1. 访问系统，点击「注册」进入注册页面
2. 填写注册信息：用户名（3-20 字符）、邮箱、密码（≥8 位，含大小写和数字）、验证码
3. 点击「注册」按钮完成注册
4. 系统会发送邮箱验证邮件（如果启用了邮件服务）
5. 注册成功后自动跳转到登录页面

### 登录系统

1. 输入邮箱、密码和验证码
2. 点击「登录」按钮
3. 登录成功后跳转到首页
4. 系统使用 JWT Token 进行身份验证，支持 Token 自动刷新

> ⚠️ **安全提示**：连续 5 次登录失败后账户将被锁定 15 分钟。

### 忘记密码

1. 在登录页面点击「忘记密码」
2. 输入邮箱和验证码
3. 系统发送密码重置邮件
4. 点击邮件中的重置链接设置新密码

### 修改密码

1. 登录系统后，点击右上角用户头像
2. 选择「设置」
3. 在设置页面中找到「修改密码」
4. 输入当前密码和新密码
5. 点击「确认修改」

### 退出登录

1. 点击右上角用户头像 → 选择「退出登录」
2. 系统清除本地 Token 并跳转到登录页

## 首页与多维表管理

首页提供四个导航标签：

- **首页**：收藏与全部卡片视图
- **全部**：列表视图与分页
- **模板**：10 种预置模板
- **分享**：我分享的 / 分享给我的多维表

### 创建多维表

1. 点击首页右上角「新建」按钮
2. 在弹出对话框中选择创建方式：
   - **创建空白多维表**：从零开始创建
   - **从模板创建**：选择预置模板快速创建
3. 填写多维表信息：
   - **名称**（必填，1-50 字符）
   - **描述**（选填，最多 200 字符）
   - **图标**：从 10 个预设图标中选择
   - **颜色**：从 8 种预设颜色中选择
4. 点击「创建」完成

### 管理多维表

- **编辑**：点击卡片右下角菜单 → 编辑，修改名称、描述、图标和颜色
- **删除**：点击卡片右下角菜单 → 删除（删除操作不可恢复）
- **收藏/取消收藏**：点击卡片上的星标图标
- **搜索**：在顶部搜索栏输入关键词搜索多维表
- **打开**：点击卡片直接打开多维表（在新标签页中打开）

### 分享视图

在「分享」标签页中：

- **我分享的**：查看自己创建的分享链接，支持复制链接和删除分享
- **分享给我的**：查看其他用户分享给我的多维表
