# 系统管理

系统管理是 SmartTable 的后台管理模块，仅管理员可访问。通过系统管理，可以配置全局参数、管理用户账号、维护邮件服务、查看操作日志等，保障平台安全、稳定运行。

## 访问系统管理

1. 点击右上角用户头像。
2. 选择「系统管理」进入后台。
3. 系统管理包含多个功能模块，通过左侧或顶部标签切换。

::: tip 权限说明
系统管理仅对管理员角色开放。普通用户、编辑者、查看者无法访问。
:::

## 用户管理

用户管理模块用于管理平台内的所有用户账号，包括添加、编辑、禁用、删除、重置密码等操作。

### 用户列表

用户列表展示平台所有用户的基本信息：

| 字段 | 说明 |
| --- | --- |
| 邮箱 | 用户登录账号 |
| 姓名 | 用户显示名称 |
| 角色 | 管理员 / 工作区管理员 / 编辑者 / 查看者 |
| 状态 | 活跃 / 未激活 / 已暂停 / 已删除 |
| 创建时间 | 账号创建时间 |

### 筛选与搜索

- 按邮箱或姓名搜索用户。
- 按角色筛选。
- 按状态筛选。

### 添加用户

管理员可以手动创建新用户：

1. 点击「添加用户」按钮。
2. 输入邮箱、姓名、初始密码。
3. 分配角色。
4. 点击保存。

### 编辑用户

- 修改用户姓名、角色。
- 禁用或激活账号。
- 重置用户密码。

### 批量删除

- 勾选多个用户。
- 点击「批量删除」可一次性删除多个账号。

## 系统配置

<img src="/images/user-guide/basic-features/system-management/system-management-config.png" alt="系统配置" style="max-width: 100%; border: 1px solid #e0e0e0; border-radius: 4px;">

系统配置模块用于设置平台全局参数，分为基础配置、安全配置、邮件配置和其他配置。

### 基础配置

| 配置项 | 说明 | 当前状态 |
| --- | --- | --- |
| 系统名称 | 平台显示名称 | 预留，暂未启用 |
| 系统描述 | 平台描述信息 | 预留，暂未启用 |
| 每页记录数 | 表格默认分页大小 | 预留，暂未启用 |
| 时区模式 | UTC 或本地时区 | 已启用 |
| 本地时区 | 选择具体时区名称 | 已启用 |

#### 时区配置

- **UTC 模式**：所有时间按 UTC 存储和展示。
- **本地时区模式**：选择时区后，按该时区解释和展示时间。
- 常用时区：Asia/Shanghai、Asia/Hong_Kong、Asia/Tokyo、America/New_York 等。

### 安全配置

| 配置项 | 说明 |
| --- | --- |
| 密码最小长度 | 密码最少字符数，范围 6 ~ 50 |
| 需要大写字母 | 密码是否必须包含大写字母 |
| 需要小写字母 | 密码是否必须包含小写字母 |
| 需要数字 | 密码是否必须包含数字 |
| 需要特殊字符 | 密码是否必须包含特殊字符 |
| 会话超时时间 | 用户无操作后自动退出登录的时间（分钟） |
| 允许注册 | 是否开放用户自助注册入口 |
| 启用双因素认证 | 预留功能，暂未启用 |

#### 密码规则

配置密码复杂度后，所有用户在注册、修改密码时都会实时校验：

- 长度是否符合要求。
- 是否包含必须字符类型。
- 不符合规则时无法提交。

#### 注册开关

- 开启时，登录页显示注册入口，用户可自助注册。
- 关闭时，隐藏注册按钮并拦截注册请求，仅管理员可添加用户。

### 邮件配置

邮件配置用于启用平台的邮件发送能力，支持 SMTP 服务器。

| 配置项 | 说明 |
| --- | --- |
| 启用邮件服务 | 总开关 |
| SMTP 服务器 | 如 smtp.example.com |
| SMTP 端口 | 如 25、465、587 |
| 发件人邮箱 | 显示的发件人地址 |
| 发件人显示名称 | 发件人名称 |
| SMTP 账号 | SMTP 认证账号 |
| SMTP 密码 | SMTP 认证密码 |
| 加密方式 | SSL / TLS / 无 |

#### 测试邮件

配置完成后，可输入测试邮箱地址，点击「发送测试邮件」验证配置是否正确。

#### 邮件模板

系统管理还提供邮件模板管理功能：

- 注册验证邮件
- 密码重置邮件
- 通知邮件
- 自定义模板

### 其他配置

| 配置项 | 说明 | 当前状态 |
| --- | --- | --- |
| 启用日志记录 | 是否记录操作日志 | 预留，暂未启用 |
| 日志保留天数 | 日志保留时长 | 预留，暂未启用 |
| 启用性能监控 | 是否开启性能监控 | 预留，暂未启用 |

## 操作日志

操作日志模块记录平台上的关键操作，便于审计和排查问题。

### 记录内容

- 操作人
- 操作类型（创建、更新、删除、登录等）
- 操作对象
- 操作时间
- IP 地址
- 操作结果

### 日志用途

- 追踪数据变更来源。
- 排查安全事件。
- 满足合规审计要求。

## 邮件日志与统计

系统管理还提供邮件发送日志和统计功能：

- 查看每封邮件的发送状态。
- 查看邮件发送失败原因。
- 统计邮件发送量和成功率。

## 注意事项

- 修改安全配置后，已登录用户不会立即被强制退出，但下次登录或修改密码时会生效。
- 修改时区配置后，历史数据的展示时间可能会发生变化。
- 邮件密码等敏感信息在界面上通常以密文显示。
- 重要配置修改前建议备份当前配置。
