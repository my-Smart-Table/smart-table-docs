# 核心功能

SmartTable 提供丰富的核心功能，满足个人和团队的数据管理需求。

## 多视图支持

SmartTable 支持多种数据视图，帮助您从不同角度查看数据：

- **表格视图**：传统的电子表格形式，适合批量编辑和数据分析
- **看板视图**：以卡片形式展示任务流程，适合项目管理
- **甘特图**：展示项目时间线和任务依赖关系
- **日历视图**：在日历上展示时间相关的事件和任务

## 丰富的字段类型

SmartTable 支持 20+ 种字段类型：

- 文本、多行文本、数字、日期
- 选择、多选、人员、关联
- 公式、附件、链接、复选框

每种字段类型都有特定的配置选项，满足不同的业务需求。

## 实时协作

支持多人实时协作编辑：

- 实时查看协作者的光标位置
- 自动同步数据变更
- 支持评论和@提及
- 详细的操作历史记录

## 工作流自动化

通过可视化工作流设计器，您可以：

- 设置触发条件
- 配置自动化动作
- 发送邮件通知
- 调用 Webhook

## 权限管理

灵活的权限控制：

- 基于角色的权限管理
- 字段级权限控制
- 数据表共享设置
- 公开链接分享

## 数据导入导出

支持多种数据格式：

- 导入 CSV、Excel、JSON
- 导出 CSV、Excel、JSON
- 数据迁移工具
