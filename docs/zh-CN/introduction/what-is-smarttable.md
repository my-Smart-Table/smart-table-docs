# SmartTable 是什么？

SmartTable 是一个开源的智能多维表格系统，提供了强大的数据管理和协作功能。

## 核心特性

### 多视图支持

- **表格视图**：经典的数据展示方式，支持排序、筛选、分组
- **看板视图**：适合任务管理和流程跟踪
- **甘特图**：项目进度可视化管理
- **日历视图**：时间线数据展示
- **画廊视图**：图片和文件展示
- **表单视图**：数据收集和分享

### 实时协作

- 多人实时编辑
- 光标位置同步
- 操作历史记录
- 冲突自动解决

### 丰富的字段类型

支持 20+ 种字段类型：

- 基础类型：文本、数字、日期、邮箱、电话、URL
- 高级类型：关联、查找、公式、汇总
- 特殊类型：附件、成员、评分、进度条

### 工作流自动化

- 可视化工作流设计器
- 多种触发器（定时、记录变更、Webhook）
- 丰富的动作节点（发送邮件、更新记录、触发 Webhook）
- 条件分支和循环处理

## 技术架构

- **前端**：Vue 3 + TypeScript + Vite
- **后端**：Flask + SQLAlchemy
- **数据库**：SQLite / PostgreSQL
- **实时通信**：WebSocket
